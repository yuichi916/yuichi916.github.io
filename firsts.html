数学 — ラムゼー数・ラドー数 R(F4,F4) = 18 答えの出ていなかったラムゼー数を5つ、ラドー数を2つ、初めて決めた R(F₃,F₅)=21R(F₄,F₅)=22R(K₃,₃,K₃,₄)=19R(K₂,₄,K₃,₅)=194色のラドー数 313・625 SATソルバーが出した証明は、検査器 cake_lpr ですべて検証しました。 論文とデータを Zenodo で公開・査読前 確かめ方と、届かなかった挑戦まで →
古代の巻物 — Vesuvius Challenge 炭になった2000年前の巻物の、解像度のちがう2つのCTを自動で重ねる方法を作った 別の巻物で第三者が試したところ、公開されている重ね方より誤差が小さくなりました（1.20・1.16 対 1.35・1.50 ボクセル）。公式リポジトリへの提出は、管理者の確認がつかないまま14日の期限で自動的に閉じられました（2026-11-16）。コードと再現の記録は公開のままです。 第三者が再現・公式には未採用 提出したコード ↗GitHub の pull request と、第三者の再現の記録 解説動画「炭の巻物を読む」↗#1 巻物と挑戦のしくみ／#2 重ね方を作った話
学び — つまずき図鑑 難しい問題を、すべて動画で説明する 人がつまずく所を、1つずつ標本にして動画に。画面の確率と実験の数字は全部コードで検算し、そのコードも公開しています。 公開中・挑戦中 図鑑を開く → 学び — 難問ほどき 99%の人がわからない問題を、99%の人がわかるように 東大入試などの難問を、最初の一手からほどく動画シリーズ。2026年度 東京大学 理系数学の全6問を、1問ずつ最後まで。答えの数値はコンピューターでも計算して、解答例と突き合わせています。 東大2026 全6問 完結 シリーズを見る → 動画 動画の公開前チェックを全自動に。編集ソフトなしで半年138本 音量、字幕のはみ出し、止まった画面。公開の前に機械が止めます。コードの全部と、ブラウザで動くチェックのデモつき。 コードと手順を公開中 作り方の完全版 → 物語 フルボイスのサウンドノベルを、1週間で 全15話・3つの結末の『正解の外側』。3D・画像・音声・作曲・ゲームUI・物語の設計という専門外の6分野を、AIと組んで越えました。 ブラウザで無料公開中 読んでみる →
ゲーム 見たことのないルールのゲームを、短い期間で 一筆花火2線の始まりから火が追ってくる。物語モード全7章と世界ランキングつき 一筆花火2 の遊べる場所itch.io・Game Jolt・PLiCy・Tsukutta・Playgama・Microsoft Store と、実況・配信のご案内 一筆花火線を1本引くと、夜空の花火が全部ひらく。ステージ2『雪の山里』も ツナラベ！ルールのちがう2つの盤のパズルが、直接戦う +1 Balloon風船だけで宇宙まで飛ぶ。Roblox で公開中 ゲームをすべて見る →毎日1問のクイズ、漢字、立体の数独、将棋の対戦パズルほか

「初」の言い方の決まり →
  1. 探すまだ答えのない所を、文献と一覧で確かめる
  2. 作り切るAIと組んで、最後まで動く形にする
  3. 確かめる証明の検査器、第三者の再現、自動チェックで裏を取る
  4. 全部出すコード・データ・失敗まで公開し、まちがいは訂正して残す
