確率のつまずき4つ — 検算コード

動画の画面に出る確率と実験の数字は、すべて下の Python コードで計算・実験し、assert（一致しなければ止まる検査）を通したものです。

今日の標本

  1. コイン2枚で表と裏が1枚ずつ … 1/2（同様に確からしい）
  2. サイコロ3個の合計9と10 … 25通りと27通り（順列と組合せ）
  3. 23人のクラスに同じ誕生日の人がいる確率 … 約51%（計算では50.7%。余事象）
  4. 表が5回続いた次 … それでも約50%（独立）

検算 14件（すべて一致）

  • coin_two_mixedコイン2枚で表裏1枚ずつ = 2/4 = 1/2✓
  • coin_sim_100001万回: 表表 2,488・表と裏 4,991・裏裏 2,521（まざりだけ約2倍）✓
  • balls_two_red赤玉2個・白玉1個から2個で両方赤 = 1/3✓
  • dice3_partitions組み合わせは 9も10も 6つずつ✓
  • dice3_count並べ方で数えると 9は25/216・10は27/216✓
  • dice2_sum11サイコロ2個で11は2通り（5と6、6と5）✓
  • dice3_sim21万6千回で 9は24,955回・10は26,764回✓
  • birthday2323人で同じ誕生日の組がいる = 50.7%（22人は 47.6%）✓
  • birthday_meter10人12%・20人41%・22人48%・23人51%・40人89%✓
  • birthday_pairs2323人の2人組 = 22+21+…+1 = 253組✓
  • birthday_sim23人のクラス10万組で同じ誕生日あり 50,956組✓
  • birthday_self自分と同じ誕生日の人が半分をこえるのは 自分以外に253人✓
  • six_seq_eq表6連続も、表5回のあと裏も、ばらばらの並びも 1/64✓
  • streak_sim100万回で直前5回が表 31,586回のうち次も表 15,866回（50.2%）✓

実験はコンピューターの乱数で行い、乱数の種（seed）を固定しています。numpy 1.26 で同じ結果になります（版がちがうと乱数の並びが変わることがあります）。誕生日は1年を365日（2/29を除く）、どの日も同じ確率として計算。コインとサイコロは、どの面も同じ確率で出るものとしています。

コード

script_ep01.py（台本と検算を1つにしたファイル）／ checks.json（結果）
