About — Rune Cube

数独に、
奥行きをひとつ足す。

異世界立体数独 ルーン・キューブは、ブラウザで遊べる 3D 数独です。 宙に浮く立方体のマスに、ルーン（または数字）を置いていきます。 縦・横・奥のどの列にも同じ記号を重ねない、立体のパズルです。ふつうの 9×9 の数独も同じ画面で遊べます。 無料で、インストールもいりません。スマートフォンにも対応しています。

01 — Ruleルールはひとつ

ふつうの数独は、縦と横の2方向（と 3×3 のブロック）で同じ数字が重ならないように埋めていきます。 立体キューブではそこに奥行きが加わります。X・Y・Z のどの方向から見ても、1本の列に同じ記号が1回ずつ入るように並べます。 初級は 3×3×3、中級は 4×4×4、上級は 5×5×5 で、立方体が大きくなるほど記号の種類も増えます。

記号は「数字」と「ルーン」から選べます。はじめは数字です。ルーンは9種類あり、それぞれ色と属性の名前がついています。

炎・水・風・地・雷・光・闇・氷・花

問題は開くたびに作られます。解いている途中で、同じ列に同じ記号が重なったマスは赤く脈打ちます。正解と違う記号を置くとミスとして数えられ、「その方向に同じルーンが…」という知らせが出ます。

02 — How to play遊び方

  1. モードを選ぶ — 開始画面で「立体キューブ」か「平面 9×9」を選び、難易度と記号を決めて「冒険をはじめる」を押します。
  2. キューブを回す — ドラッグで好きな向きに回せます。ホイールやピンチで拡大・縮小します。
  3. 層を1枚だけ見る — 奥のマスが見えにくいときは、右のスライダーで断面を1枚だけ表示します。X／Y／Z で切り口の向きを変えられます。
  4. 展開する — 🧊 のボタンで立方体をばらして、全体を見渡せます（立体キューブのみ）。
  5. 記号を置く — マスを選ぶと、そのそばにパレットが出ます。選んだマスを通る縦・横・奥の列が光り、同じ記号のマスも強調されます。
  6. メモする — パレットの「✎ メモ」に切り替えると、候補の記号を小さく書き込めます。
  7. ヒントを使う — 🔮「魔法の導き」で、空いているマスを1つ正しく埋めてくれます。回数は初級 5 回・中級 4 回・上級 3 回です。

平面 9×9 モード

ふつうの数独を、同じ異世界の景色の中で遊ぶモードです。難易度は「やさしい・ふつう・むずかしい」の3段階で、 盤は「テーブルの上」（真上から見下ろす木の盤）と「宙に浮く」（魔法の盤）から選べます。 ふつうの数独と同じく、縦・横と 3×3 のブロックのそれぞれに 1〜9 が1回ずつ入るように埋めます。

03 — Features記録と、解放される世界

クリアの評価

クリアすると、タイム・ミスの数・ヒントの数と、★1〜3 の評価が出ます。ミスやヒントが多いほど★は減ります。 クリアのたびに経験値が入り、経験値 100 ごとにレベルが1つ上がります。経験値は、盤が大きいほど、★が多いほど増え、ノーミスなら上乗せがあります。ノーミス、ヒントなし、5×5×5 の制覇などで実績も記録されます。

今日の挑戦（デイリー）

「今日の挑戦」は日付ごとに決まった問題で、同じ日なら同じ問題になります（立体は 4×4×4、平面は「ふつう」）。 毎日続けると、連続日数（🔥）が伸びます。

4つの世界

盤のうしろの景色は、クリアした回数で増えていきます。最初は「闇のファンタジー」、2回で「エンチャント」、5回で「ヴァルハラ」、9回で「トレジャーアイランド」が開きます。

結果をシェアする

結果画面の「結果をポスト」で X に、「結果をコピー」でほかの場所に、盤の大きさ・★・タイム・ミスの数を書いた短い文を貼れます。デイリーのときは日付と連続日数も入ります。

04 — FAQよくある質問

無料で遊べますか。登録は必要ですか。
無料です。会員登録もインストールもいりません。ブラウザでページを開けば遊べます。
スマホでも遊べますか。
遊べます。指でドラッグするとキューブが回り、ピンチで拡大・縮小できます。マスをタップすると、そのそばに置く記号を選ぶパレットが出ます。
3D数独のルールは、ふつうの数独とどう違いますか。
ふつうの数独は縦と横の2方向（と 3×3 のブロック）で同じ数字を重ねないパズルです。立体キューブでは奥行きが加わり、縦・横・奥の3方向のどの列にも、同じ記号が1回ずつ入るように並べます。
ふつうの数独も遊べますか。
遊べます。開始画面のモードで「平面 9×9」を選ぶと、ふつうの数独になります。盤は「テーブルの上」と「宙に浮く」から選べます。
途中でやめても続きから遊べますか。
遊べます。解いている途中の盤は同じブラウザに保存され、開始画面の「続きから」で再開できます。レベルや連続日数、クリア数も同じブラウザに残ります。
AI で作ったのですか。
コードは Claude Code で書きました。背景の4つの世界は、KitBash3D の3D素材を Blender で360°の画像に描き出したものです。

05 — How it's madeどうやって作ったか

ゲームは1枚の HTML で動いていて、3D の描画は Three.js です。サーバー側の処理はなく、記録はブラウザの中に保存します。 コードは Claude Code で書きました。問題は立体・平面とも、答えが1つに決まることを確かめながら、その場で作っています。

うしろの4つの景色は、KitBash3D の3Dキット（ダークファンタジー・エンチャント・ヴァルハラ・トレジャーアイランド）を Blender に読み込み、360°の画像として描き出したものです。 平面モードの「テーブルの上」の木目にも、同じキットの板材のテクスチャを使っています。
