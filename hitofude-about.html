About — 一筆花火

線を1本。
夜空が全部ひらく。

一筆花火は、ブラウザで遊べる一筆書きのパズルです。 指やマウスで線を1本ひくと、その線が導火線になります。火が走り、花火玉がひらき、 爆発が線の別の場所にも燃え移って、花火が連鎖していきます。8つの夜をこえるランと、CPU と点を取り合う「花火合戦」の2つの遊び方があります。 無料で、登録もインストールもいりません。スマホは縦画面、PC は横画面で遊べます。

01 — Whatどんなゲームか

盤面には花火玉が散らばっています。ひける線は基本的に1本だけで、線の長さには限り（墨）があります。 線に火がつくと導火線のように火が走り、線にふれた玉がひらきます。ひらいた玉の爆発がまわりの玉に届くと、そこからさらに連鎖が広がります。 爆発が線の別の場所にふれると、その場所からも火が走ります。どこに、どんな形で線をひくかを考えるパズルです。

点は「点×倍率」で決まります。金の玉をひらいたときと、10 連鎖ごとに倍率が上がり、盤面の玉を全部ひらくと ×2 になります。 連鎖が進むほど花火は少しずつ小さくなるので、遠くの玉の群れへは線で火を運ぶ必要があります。

いま遊べるのはステージ1『川辺の夏祭り』です。八夜で1ステージで、次のステージは景色と仕掛けを変えて準備中と、ゲームの中に書いています。

02 — How to play遊び方

  1. 線をひく — 盤面を指（PC はマウス）でなぞって、線を1本ひきます。使える墨の量は夜ごとに決まっています。
  2. 点火する — 線に火が走り、花火玉がひらいていきます。点火したあとは見守るだけです。
  3. 目標点をこえる — 夜ごとに目標点があります。こえるとお守りを1つもらえ、次の夜へ進みます。
  4. お守りを育てる — お守りは5つまで持てます。同じお守りをもう一度選ぶと Lv2・Lv3 に強くなります。
  5. 八夜目まで通す — 八夜目の尺玉は「大トリ」です。線の火でしかひらかず、それまでに多くの玉をひらいているほど倍率が大きく上がります。

夜ごとに増える仕掛け

夜が進むと、新しい仕掛けが1つずつ加わります。二夜目は大玉、三夜目は千輪、四夜目は提灯、五夜目は雲、六夜目は湿った玉、七夜目は仕掛け縄、八夜目は尺玉です。 三夜目からは、夜ごとに景色（群れ・天の川・輪・屋台の列）も変わります。

大一番（三夜目・六夜目）

三夜目と六夜目は大一番で、妖怪が現れます。線の引き方が「まっすぐ」「鏡」「闇夜」「一瞬」のどれかに変わります。 こえるとお守りを2つもらえ、はじめて勝った妖怪は仲間になって、その妖怪の伝説のお守りが出るようになります。

夜をまたいで残るもの

  • 墨壺 — 使わなかった墨の半分を、次の夜に持ち越せます。
  • 星 — 夜ごとに3つまで（目標・目標の3倍・全部ひらく）。お守り選びの屋台で、選び直し・墨・予備の提灯に使えます。
  • 予備の提灯 — 目標に届かず散っても、提灯があればその夜をもう一度ひけます。
  • 願い札 — 夜ごとに1枚。叶えて夜をこえると、星がもう1つ増えます。

03 — Features特徴とモード

今夜の月と「今夜の一筆」

その日の本物の月の形（新月から有明の月まで8つ）によって、ルールが1つ変わります。 「今夜の一筆」は毎晩0時（日本時間）に入れ替わり、同じ日に遊ぶ人はみんな同じ夜・同じ大一番を遊びます。

お守りの型

お守りには金・提灯・連鎖・墨・大トリ・賭けの型があります。同じ型を3種類（提灯は2種類）そろえると「型そろい」で点に掛け算がつきます。 Lv3 まで育てると、ふるまいが1つ変わります。

花火合戦（CPU と対戦）

同じ夜空で CPU と点を取り合う三番勝負です。相手は先に線とお邪魔玉（黒玉）を見せます。あなたは全部見てから線を1本ひき、お邪魔玉を1つ置きます。 相手の線に先に火を届けると横取りになります。お邪魔玉に1番目に届いた線の火は消え、2番目に届いた別の線の火で大爆発して、届けた人の点になります。 勝つと次の相手が出てきます。

遊んだあと

  • 散ったときは、案内役のヒノコが次に効くコツを1つ教えてくれます。
  • 結果には、線の形から「筆跡」（稲妻・渦巻き・波乗り など）が出ます。
  • 結果画面から、同じ夜で勝負するリンクと、いちばんの一筆を再生するリンクを送れます。
  • 遊ぶたびに「花火師の格」が上がり、お守り・着せかえ・ヒノコの色などが1つずつ開きます。八夜を通すと、ルールが1つずつ厳しくなる「段位」を選べます。

操作と画面

スマホは縦画面で指、PC は横画面でマウスを使います。画面の向きはタイトル画面で「自動・横（PC）・縦（スマホ）」から選べます。 PC では Space／Enter で次へ、F で早送り、M で効果音、B で BGM、Esc／P でひと休みです。 言葉は日本語と English から選べます。

04 — FAQよくある質問

一筆花火は無料ですか。登録は必要ですか。
無料です。会員登録もアプリのインストールもいりません。ブラウザでページを開けば、そのまま遊べます。
スマホでも遊べますか。
遊べます。スマホは縦画面で、指で線をひきます。PC は横画面で、マウスで線をひきます。画面の向きは「自動・横・縦」から選び直せます。
記録は保存されますか。
同じブラウザの中に保存されます。花火師の格や開いたお守り、途中の夜も残り、「ひと休み」から続きを遊べます。ブラウザの保存データを消すと消えます。
毎日、問題は変わりますか。
変わります。「今夜の一筆」は毎晩0時（日本時間）に入れ替わり、その日に遊ぶ人はみんな同じ夜・同じ大一番を遊びます。今夜の月の形によって、ルールも1つ変わります。
英語でも遊べますか。
遊べます。タイトル画面で日本語と English を切り替えられます。
配信や実況動画で使ってもよいですか。
ゲームの画面に「配信や動画で使うのは自由です（連絡は要りません）」と書いています。そのとおり、連絡なしで使ってかまいません。
AI で作ったのですか。
AI を使って作りました。コードは Claude Code で書き、BGM の3曲は Suno で作りました。itch.io の公開ページでも、コード・音・文章に AI の補助を使ったと表示しています。

05 — How it's madeどうやって作ったか

ゲームは HTML と JavaScript で書いていて、サーバー側の処理はありません。コードは Claude Code で書きました。 BGM は Suno で3曲作り、線を考えているあいだの曲、火が走っているあいだの曲、満開のときの曲に分けて鳴らしています。 2026年9月26日にこのサイトで公開し、itch.io にも置いています。

作る前に、2025〜2026年9月に広がったゲームを Steam・スマホ・ブラウザ・日本の4方向から調べ、くり返し出てくる部品から「今月の型」を出しました。 一筆花火はその型どおりに作ったゲームです。調べ方の手順と、初版で失敗して作り直した経緯は研究ノートに書いています。
