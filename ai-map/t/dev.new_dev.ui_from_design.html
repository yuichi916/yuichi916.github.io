専門家と比べて

単純なコンポーネントはジュニアを超えるが、デザインシステム全体の一貫性維持はミドル未満

できること

Figma/画像から視覚的に近いレスポンシブコードを生成（複雑デザインで視覚一致度80〜94%の報告）

まだできないこと

画像だけでは伝わらないブランドの微妙なトーンや、デザインシステムの拡張判断

なぜそうなのか

画像はコンテキスト情報（余白ルール、状態遷移など）を欠くため、モデルが暗黙のデザイン意図を補えない

これからの予測の根拠

Figma MCP等の構造化データ連携が進むほど精度が上がる傾向が明確なため、2028年には視覚一致度がほぼ飽和すると予測

いま使える主な道具

v0 (Vercel)、Locofy、Builder.io、Figma Dev Mode MCP
