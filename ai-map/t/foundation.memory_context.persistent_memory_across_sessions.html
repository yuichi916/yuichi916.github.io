専門家と比べて

秘書やアシスタントが数年かけて蓄積する『相手を知る』記憶に比べ、AIの記憶は個別事実の断片的蓄積にとどまる

できること

Claudeはカテゴリ化された個別記憶をリアルタイム更新、ChatGPTは2026年6月開始の『Dreaming』で会話横断の継続的統合を実装

まだできないこと

プラットフォーム間の記憶移植ができず（Claude↔ChatGPT間で自動連携不可）、各社独自のリテンション機能に閉じている

なぜそうなのか

記憶はベンダーごとの製品機能として実装されており、業界標準的な相互運用プロトコルが存在しない

これからの予測の根拠

記憶の相互運用性は業界標準化の動きがなく、2028年時点でも各社独自実装が続く可能性が高い（横ばい予測）
