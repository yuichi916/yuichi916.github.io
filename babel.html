Library of Babel

蔵書 の 宇宙 を、夜 に 旅する。

個人蔵書 40,546 冊を bge-m3 全文埋め込みと NDLサーチ・Wikidata・Open Library で繋ぎ、 WebGL で 書架の宇宙 にした。20-30 銀河に分かれた本たちを、 サイコロ・★お気に入り・10 実績で旅しながら、まだ知らない自分の本と出会う。

375冊
1,008関係性
8銀河
5類似度ソース
書架 へ 入る → 音楽 の 宇宙 へ

七層の 類似度 を、書架の間隔として描く。

本同士の距離は単一の物差しでは測れない。著者の系譜、ジャンルの近さ、文体の共鳴、 時代の空気、賞のコホート、そして本文そのものが内に持つ意味。 Library of Babel はこれらを 七つのソース から束ね、各エッジに重みをつけて重ねる。

i.本文埋め込み

43,000 冊の全文を bge-m3 (1024 次元) でベクトル化し、章単位 chunk の混合プーリングで一冊一点に。最も濃密な信号。

ii.NDLサーチ

国立国会図書館の書誌・主題・件名で和書を補強。タイトルだけでは見えない学術分類を引き寄せる。

iii.Wikidata

同著者・同シリーズ・影響関係 (P737) を SPARQL でグラフ化。文学史の系譜を直接エッジに。

iv.Open Library

洋書の subject + 表紙画像 + 出版年。和書中心の蔵書に英語側の文脈を持ち込む補助線。

v.読書メーター

「この本を読んだ人がよく読む本」は集合知の頂点。和書類似度の決め手だが、最も丁寧に扱う。

vi.受賞コホート

本屋大賞・直木賞・芥川賞・このラノ・このミス・Booker・Pulitzer は同じ年の文化を一塊にする。

銀河 は データから 自動命名 される。

固定の 6 ジャンルでは届かない解像度を、BERTopic と HDBSCAN による教師なし分類で得る。 そこに バベル風の詩的命名 (魔導の七室 / 異界の門 / 謎の塔 / 恋慕の螺旋 / 学知座 ...) を当て、 無限に増殖する書架の階に意味を与える。
