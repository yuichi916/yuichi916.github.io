# 小説の面白さ測定器 — 検証レポート

2026-09-21 ／ `C:\projects\shinsa-bench`

## 要旨

原稿の冒頭12,000字だけを読んで、読者がその作品を高く評価するかを当てる。
発表後の情報（ブックマーク数・評価人数・話数）は一切使わない。

| | AUC | 根拠 |
|---|---:|---|
| **未知のジャンルに当てる** | **0.792** | ジャンルを丸ごと外して学習し、そのジャンルに当てた実測（5通り）の加重平均 |
| 学習済みジャンル（著者単位5分割） | 0.781 | 1126作品・著者879人・5ジャンル（0.755–0.807） |
| 異世界恋愛の専用版 | 0.797 | 481作品（0.758–0.835） |
| 偶然 | 0.500 | 並べ替え検定 p=0.00498（偶然の最大 0.565） |

上位10%を選ぶと高評価が **88%**（選ばなければ 50%）。

## 1. ジャンルを跨げるか（本レポートの主題）

「ジャンル不問」を名乗るには、**学習していないジャンルで通用する**ことを示す必要がある。
ジャンルを1つずつ完全に外して学習し、そのジャンルに当てた。

| ジャンル | 作品数 | そのジャンル自前で学習 | **そのジャンルを外して学習** |
|---|---:|---:|---:|
| 異世界恋愛 | 481 | 0.797 | **0.807** |
| ハイファンタジー | 272 | 0.740 | **0.750** |
| 現実世界恋愛 | 216 | 0.787 | **0.795** |
| ローファンタジー | 72 | 0.663 | **0.742** |
| ヒューマンドラマ | 85 | 0.764 | **0.775** |
| **加重平均** | **1126** | **0.782** | **0.792** |

**外して学習したほうが、そのジャンル自前で学習するより良い。**
ジャンル固有の要素はほぼ無く、データ量のほうが効いている。
未知のジャンルの原稿を持ち込まれても、この水準で当たると見込める。

## 2. 何を正解にしているか

**評価の重さ = 総合評価点 ÷ 評価した人数**（1人最大10点）。ブックマーク数ではない。

予備調査（n=134）で、LLMの「面白い」判定は
- ブックマーク数と **無相関**（r = −0.061, p = 0.48）
- 評価の重さと **相関**（r = +0.309, p = 0.0003、多重比較補正後も有意）

**人を集める力と、読んだ人が高く評価することは別の軸。** この測定器は後者だけを測る。
各ジャンル内の上位25%と下位25%を使い、中間50%は使わない。

## 3. 商業出版にも通じるか

なろうだけで決めた重みを、商業出版された小説385冊にそのまま当てた。商業書籍は学習に使っていない。

| 集団 | 冊数 | 読みの評点（中央値） |
|---|---:|---:|
| なろう高評価 | 241 | 4.66 |
| **商業出版の小説** | **385** | **4.62** |
| なろう低評価 | 240 | 4.07 |
| 実用書・随筆（除外分） | 48 | 3.95 |

商業の小説 対 なろう低評価 **0.736**／
商業の小説 対 なろう高評価 0.456（互角）。
**商業出版とWeb小説の高評価作品を区別しない。** 体裁や組版を見ているのではない。

軸別で最も強いのは**具体描写の力 0.896**（商業5.3 / なろう高4.0 / なろう低3.0）。
商業が高評価なろうをも上回る唯一の軸で、商業出版とWeb小説を最も強く分けている。

## 4. 何が面白さを作っているか（発見した因子）

13軸のうち5軸は人が決めたのではなく、**コーパスから取り出した**。

468件の指摘を束ねて14の型を得て、採点軸として効くものを採った。

| 具体描写の力 | 0.720 | **発見** |
| 掛け合いテンポ | 0.715 | **発見** |
| 読者を集めると思うか | 0.697 | 当初の9軸 |
| 語り口の個性 | 0.685 | 当初の9軸 |
| 唐突な急変（低いほど良い） | 0.326 | **発見** |

テンプレ展開でも次の一手は読めない作品がある。

### 外した軸

**「何が懸かっているか」を削除した。** 3つの独立したデータで効かなかった。

| 測り方 | AUC |
|---|---:|
| 全ジャンル版のなろう作品 | 0.468 |
| 異世界恋愛の高評価 対 低評価 | 0.504 |
| 商業出版の小説 対 なろう低評価 | 0.442（**逆向き**。商業5.0 < なろう低5.3） |

**懸かっているものを明示的に書き下すのは、むしろ弱い書き手の癖だった。**

### 効かないと分かった要素

創作論で必ず語られるのに、高評価と低評価を分けなかったもの。

| 要素 | AUC |
|---|---:|
| 何が懸かっているか | 0.504 |
| 説明過多 | 0.516 |
| 謎の掴み | 0.526 |
| 視点混乱 | 0.497 |
| 落差・転調 | 0.533 |

「冒頭で謎を置け」「説明を減らせ」「何が懸かっているかを明示しろ」。
**少なくともWeb小説の読者評価に対しては、これらは高評価と低評価を分けていない。**

## 5. 採点の根拠を出せるか

3層で出せる。

**① 軸ごとの寄与** — モデルは線形なので厳密に分解できる。
寄与の合計＋切片が判定そのものになることを検算済み（差 1e-12未満）。
後付けの説明ではない。

**② 参照分布の中での位置** — 各軸が高評価群／低評価群の中央値のどちら寄りか。

**③ 本文のどこが効いているか** — 原稿をブロックに割り、引きの強さ・
面白さの型・本文からの引用・落ちた理由を返す（`shinsa_bench/interest/extract.py`）。

この③は**3度目の検定でようやく合格**した。経緯を残す。

| 検定 | 結果 |
|---|---|
| ①絶対評価（該当箇所を消して評点の落ち幅を見る） | 本文の1/5を消しても0.02点しか動かず、検出力なし |
| ②全文の二択（消した版どうしを比べる） | 判定者が83%の確率で後に見せたほうを選ぶ。両順序で一致した対は12/48（25%）で、純粋な位置選択が予測する28%と同水準＝信号なし |
| ③ブロック同士の二択 | 両順序で一致した19対のうち**19対すべて**が抽出側を支持。作品単位 8勝0敗 p=0.00781、票 p<0.0001 |

位置だけで選ぶなら、一致した対での勝率は50%になるはず。19/19は 2×0.5^19 = 3.8×10⁻⁶。

**LLMに長文2本を比較させると位置でしか選ばない。** 比較対象を短くすれば信号が出る。

## 6. どこまでの作品に使えるか

効きを決めているのは**評価した人数**であって、ブックマーク数でも話数でもない。

| 評価した人数 | 作品数 | AUC |
|---|---:|---:|
| 1〜12人 | 34 | 0.553 |
| 13〜30人 | 80 | 0.671 |
| 31〜100人 | 133 | 0.764 |
| 101〜∞人 | 236 | 0.827 |

| 話数 | 作品数 | AUC |
|---|---:|---:|
| 5〜9話 | 83 | 0.807 |
| 10〜19話 | 114 | 0.818 |
| 20〜49話 | 192 | 0.718 |
| 50〜∞話 | 94 | 0.808 |

**話数が少なくても落ちない**（5〜9話で 0.807）。読むのは冒頭12,000字＝ほぼ3話ぶんなので、
投稿間もない作品でも入力としては同じものになる。

一方、評価が12人以下の作品では 0.553 まで落ちる。
AUC を 1/√評価人数 に回帰すると R²=0.990 でよく当てはまり、
ノイズのない正解に対する見積りは **0.874【推定値】**。
落ちているのは測定器ではなく、ものさし（評価の重さ）のほうである。

**ただしこの穴は埋められない。** 異世界恋愛でブックマーク0〜2の作品のうち、
評価5人以上あるのは1,310作品中わずか1件。**読者がいない作品には正解データが存在しない。**

| 対象 | 判断 |
|---|---|
| 評価が30人以上ついた作品の選別 | 使える（0.764〜0.827） |
| 話数が少ない作品（5話〜） | 使える（話数は効きに影響しない） |
| 評価が30人未満／投稿間もない作品 | 出力は出るが、**正しいか確かめる手段がない** |
| 「これから伸びる作品」の予測 | **使えない**（スコアとブクマ数の相関 ρ=+0.192） |

## 7. 検証の規律（これを崩すと数字が嘘になる）

| 守ったこと | 理由 |
|---|---|
| 本文だけを使う | ブックマーク数・評価人数・話数は未発表原稿には存在しない。使えば検証は通っても製品では使えない |
| 測る範囲を学習時と実使用時で揃える | 学習データは3話ぶん、顧客が出すのは1本の原稿。どちらも冒頭12,000字に切る |
| 著者単位で分割する | 同じ作者が学習側と評価側に跨ると、作風を覚えただけの精度が出る |
| 重みは学習側だけで決める | 全データで重みを決めて同じデータで測るのは自己採点 |
| 位置づけは out-of-fold の分布で行う | 学習に使った予測値で百分位を引くと実際より良く見える |
| 並べ替え検定は「案を選ぶ手続きごと」行う | 3案から最良を選べば偶然でも数字は上がる。合成データで実測したところ、選ぶだけで偶然のAUCの中央値が 0.496 → 0.530 に上がった |
| 実地検証では著者ごと外す | 最初の実地検証80作品は32人の著者が較正側にも入っていた |
| epubの前付けを落とす | そのまま冒頭12,000字を読むと**目次を評価する**ことになる |
| 実用書・随筆を除く | 文庫・単行本に9〜11%混入。レーベルでは切れないのでLLMで判定 |

### 独立な検算

- 1軸AUCを sklearn の `roc_auc_score` と一致確認
- 著者分割で学習側と評価側の著者集合が交わらないことを確認
- ラベルを無作為化すると 0.502 に落ちる
- 目的変数を特徴量に混ぜると 1.000 になる
- 参照ファイルの係数を当てる自前実装と sklearn の `predict_proba` が 4.4e-16 で一致
- 寄与の分解の合計が判定と一致（差 1e-12未満）
- 符号検定が scipy の二項検定と一致

## 9. この測定器にできないこと

- **売れるかは分からない。** 測っているのは「読んだ人が高く評価するか」で、
  何人に届くか（ブックマーク数）とは実測で無相関だった（r = −0.061）
- **1作品単位では外れる。** AUC 0.792 は「高評価と低評価を1つずつ並べたとき、
  正しい方を高く採点する確率が 79.2%」という意味でしかない
- **冒頭12,000字しか見ていない。** 中盤の失速・終盤の破綻・伏線の回収は範囲外
- **直せば上がるとは限らない。** 相関を測った道具であって、因果を確かめたものではない
- **評価が30人未満の作品では、当たっているか確かめられない**（§6）
- **文学的な価値の評価ではない。** Web小説投稿サイトの読者が付けた点数を正解に置いている
- **学習したのはWeb小説5ジャンル。** 未知のジャンルは 0.792 の見込みだが、
  純文学・ホラー・推理などは実測していない
- **原稿本文は保存していない。** 参照ファイルにも成果物にも統計量と重みだけが入る

## 10. 使い方

```bash
# ジャンル不問（推奨）— txt / docx / epub / 青空文庫HTML / なろうURL
python -m shinsa_bench.cli novel interest 原稿.docx

# ジャンルが分かっている場合（異世界恋愛なら 0.797 と上）
python -m shinsa_bench.cli novel interest 原稿.docx --genre 101 --html out/r.html --pdf out/r.pdf

# 使えるジャンル専用版の一覧
python -m shinsa_bench.cli novel genres
```
