About — Cabin in the Hollow

森の奥の小屋で、
焚き火を見つめる。

森の小屋は、ブラウザで開ける 360° の瞑想空間です。 深い森にぽつんとともる小屋の中を見回しながら、暖炉でゆれる焚き火を眺められます。 呼吸ガイドつきの瞑想タイマーと、薪のはぜる音・雨・森・風の環境音があり、瞑想にも、作業や眠る前の時間にも使えます。 無料で、インストールもいりません。WebGL が動くスマホと PC で開けます。

01 — The hollowどんな場所か

ページを開くと、まず小屋の入口に着きます。灯里（ともり）と蒼（そう）の二人が出迎え、「中へ入る」を押すと小屋の中に入り、焚き火の音と曲が鳴りはじめます。 中に入ると、正面に暖炉があります。画面をドラッグすると部屋の中をぐるりと見回せ、ピンチやホイールで寄ったり引いたりできます。

部屋の中には、光る印がいくつか置いてあります。印を押すと、その場所でできることが始まります。

  • 炎を見つめて瞑想する — 暖炉の前で瞑想タイマーを始めます。
  • 夜の森をのぞむ — 窓から外の森を眺めます。
  • 短編小説「焚き火は、消えない」 — この小屋のある夜の物語を読めます。
  • 処方箋「朝、ふとんから出られない君へ」 — 心を軽くする小さな方法をまとめた読みものです。
  • 灯火の文箱 — ほかの人が残した言葉を読んだり、自分の言葉を残したりできます。
  • 数独の卓 — 卓の上の盤から、平面 9×9 の数独に移れます。
  • 扉から外へ出る — 湖のほとりに出ます。

小屋の外

扉を出ると、星空の下の深い森の湖に出ます。湖のほとりでは焚き火のそばに座ったり、星を見ながら瞑想したりできます。 昼と夜はボタンひとつで切り替えられます。森の奥へ歩いていくと、歩いて回れる夜の森のシーンにつながります。

02 — How to use使い方

  1. 小屋に入る — 入口の「中へ入る」を押します。焚き火の音と曲は、ここで鳴りはじめます。
  2. 見回す — ドラッグで見回し、ピンチまたはホイールで拡大します。
  3. 音を選ぶ — 「音」のボタンで、薪のぱちぱち・雨・森のざわめき・風を、それぞれオン／オフできます。音量も変えられます。
  4. 曲を流す — 「曲」から瞑想のための曲を選べます（6曲）。
  5. 瞑想する — 暖炉の印を押し、5分・10分・20分から時間を選んで「瞑想を始める」を押します。終わったら「出る」で戻ります。

呼吸のガイド

瞑想中は、4秒で吸い、2秒とどめ、6秒で吐く呼吸のガイドが出ます。暖炉の火は、この呼吸のリズムに合わせて大きくなったり小さくなったりします。 小屋に置かれた文章には、呼吸を数える・音に浸る・灯りを見つめるという三つの鎮め方が書かれています。

03 — A tale物語モード「灯を継ぐもの ―幾夜の噓―」

入口や部屋の中の「物語」から、灯里と蒼と一緒に小屋の謎を解いていく物語を読めます。全12章で、章ごとに章題が出ます。 読み終えて2周目、3周目と読み返すと、同じ場面で見える内容が変わっていき、結末は3つあります。 途中でやめても同じブラウザなら「つづきから」で再開でき、一度たどり着いた章は章の一覧から選び直せます。

物語の音楽：君の音。（真島こころ）『映画風ピアノ音楽素材集』

04 — FAQよくある質問

無料で使えますか。登録は必要ですか。
無料です。会員登録もインストールもいりません。ブラウザでページを開けば使えます。
スマホでも使えますか。
WebGL が動くスマホと PC で使えます。指でドラッグすると見回せ、ピンチで拡大できます。WebGL が使えない環境では、小屋の静止画が表示されます。
開いても音が鳴りません。
入口の「中へ入る」を押すと、焚き火の音と曲（森の廃洋館）が鳴りはじめます。ほかの環境音や曲は、画面の「音」と「曲」のボタンから選びます。音量もそこで変えられます。
瞑想タイマーは何分ですか。
5分・10分・20分から選べます。4秒吸って、2秒とどめ、6秒で吐く呼吸のガイドがつき、暖炉の火も呼吸に合わせてゆれます。
「灯火の文箱」に書いた言葉は、ほかの人にも見えますか。
見えます。灯火の文箱は、登録なし・匿名で言葉を残せる共有のメモ帳で、残した言葉はほかの訪問者も読めます。1回に書けるのは 500 字までです。
何語に対応していますか。
日本語・English・简体中文・한국어・Español・Français・Deutsch・Português・Русский・Italiano の10言語です。画面の言語の切り替え（JP ▾）から選べます。
AI で作ったのですか。
コードは Claude Code で書きました。小屋の中と外の360°の景色は、KitBash3D の3D素材を Blender で描き出したものです。物語モードの立ち絵の表情の差分は、Stable Diffusion で顔の部分だけを描き直して作りました。

05 — How it's madeどうやって作ったか

小屋の中と湖畔の景色は、KitBash3D の3D素材（Enchanted Interiors・Enchanted）を Blender に並べ、360°の全天球画像として描き出したものです。 湖畔の景色は昼と夜の2枚を描いています。ページではそれを Three.js で内側から貼った球に映し、その中心から見回す仕組みです。 暖炉と湖畔の焚き火の炎は画像に焼き込まず、ブラウザの中でシェーダーとして毎フレーム描いているので、ずっとゆれ続けます。

雨・森・風の環境音は、ブラウザの中で合成して鳴らしています。コードは Claude Code で書きました。

瞑想のしらべ（曲）：Yurino (Mozecon4)、leberch (Pixabay)、南雲莉翠（なぐもりずの音楽室）ほか。
