# 「正解の外側」物語クラフト指針 — 蔵書43,000冊から抽出した技法と適用箇所

## 0. 世界設定の正典（2026-07-18確定 — 以後の執筆はこれに従う）

**部構成**: 第一部=廃棄層脱出篇(ep1-5) ／ 第二部=誰も泣かない街(ep6-15) ／ 第三部=沈黙の地平線(未執筆)。

**リーンの記憶モデル（「明日の記憶」の正体）**:
- 管理者AIは全住民の未来を常時シミュレートしている。実験体七号=リーンはその計算機の部品であり、
  彼女の中には**自分に関係する「計算済みの明日」の断片（キャッシュ）**が最初から入っている。
- 「なんとなく」= 予知ではなく、**管理者が先に解いた明日の答案との答え合わせ**。
  初めてのパンケーキが懐かしい・ミーラの絵を「待ってた」・ノーグの言葉の先読み・設計図が「三度目」——全てこれで説明される。
- **忘却の理由**: 廃棄=切断された彼女の器は容量固定。**今日を覚えるたびに明日の断片が上書きされて消える**
  （今日と明日が同じ器を取り合う）。カイと過ごした日々自体は失われない。
- **ep12以降の忘却**: プロトコル再接続で同期が逆流し、**今日の記憶が中枢へ吸い上げられる。
  管理者にとって価値の高い=いちばん大事な記憶から順に**（だから最初に「カイ」の名が消える）。
- **ep15後の空白**: 明日の断片が尽き、接続を焼き切った代償に器が初期化された。
  → 物語=手紙は、空の器へ記憶を再インストールする装置。

**ユーゴの動機（計画の核）**:
- 感情配給の最初期実験で最愛の人（パンケーキの焼き方を教えてくれた人）を「最適化」で喪った。
  体は町で穏やかに笑い続け、**中身だけが中枢のアーカイブに眠っている**。
- 実験体七号の人格モデルに、その人のデータを使用（→リーンの食べ方が似ている伏線の回収）。
- 中枢を支配すればアーカイブが開き、あの人を取り戻せる。**人類回復のイデオロギーは建前**。
- カイとの鏡像: どちらも「喪った人を諦められなかった男」。違いは、他人を道具にしたか否か。

**ノーグ**: 元・第二層航路管理官の**人間の能力者**（自分の道筋で「右」を選び大切な人を喪った）。
ユーゴとは互いを道具と割り切った協力関係（AIサブシステム説は誤りとして修正済み）。

## 2. 構造ルール（全話共通）

1. **章頭コールドオープン**: void背景＋未来の手紙2-3行。①この章で起きることの影 ②感情の予告 ③まだ明かさない謎、のいずれかを含む。
2. **章末は必ず引き**: ［今］の手紙に「次章の影」を1行（ep2「一人の少年の時間が尽きかけていた」）。
3. **選択肢は各話1-2個**: 物語を分岐させない「人格表現型」（返答の温度を選ぶ）。必ず合流。最も感情が張る瞬間に置く。
4. **fxは山場のみ**: flash=真実の露出/侵入、heart=心拍、shake/hit=物理、sepia=回想。乱発しない。
5. **時系列**: リーン出会い=1日目、決行=38日目。地上編: 地上1日目〜。ep10=5日目、ep11=6日目（再訪）、ep12=7日目、ep13=8日目。
