# 連載の軸（決定版）— AIエージェントのプロになる教科書

> 作成: 2026-09-26 ／ これが最新の軸。01〜03 は古い案。

## 1. この連載が言いたいこと

**プロは、プロンプトがうまい人ではない。**
Skill を作るのがうまい人でも、RAG を組むのがうまい人でもない。

そういうテクニックは大事だし、この連載でも扱う。けれど、AIは日ごとに変わる。先月覚えた書き方は、今月の新しいモデルではもういらなくなっている。**テクニックは、覚えたそばから古くなる。**

では、AIエージェントのプロとは誰か。

> **AIエージェントを通じて、自分だけの世界を、深く、速く築き、表現できる人。**
> **これまでの「当たり前」を、AIエージェントで壊せる人。**
> **AIが変わるたびに、自分の世界ごと、その変化に乗っていける人。**

ひとりでできることの大きさそのものが変わった。世の中の常識が、次々に書き換わっていく。その中で、変化に振り回されるのではなく、変化に合わせて自分の世界を育て続けられるかどうか。それが、これからの差になる。

**プロンプトのテクニックは、表現のうまさの一つにすぎない。**画家にとっての筆づかいのようなもの。大事だけれど、何を描くかの代わりにはならない。

## 2. 三つの柱

| 柱 | 意味 | 問い |
|---|---|---|
| **築く** | 自分だけの世界を、深く、速く作る | あなたにしか作れないものは何か |
| **壊す** | 既存の常識や価値の前提を、AIで外す | 「それは無理」と思われてきたことは、本当にまだ無理か |
| **乗りこなす** | AIの進化に合わせて、自分の世界を更新し続ける | 新しいAIが出た日に、何を捨てて、何を残すか |

テクニックは、この三つを支える**道具箱**として別に扱う。道具箱は古くなる前提で書き、日付を入れて更新する。

## 3. なぜ、この書き手なのか

作者は、この春から、AIエージェントと一緒に**自分の世界**を作ってきた。

- 書いた物語を、声のある、遊べるゲームにした
- 旅の記憶を、見回せる場所にした
- 好きな音楽から、まだ知らない音楽の地図を作った
- 「ひとりで入れるか」という自分のこだわりで、全国の店を調べ直した
- AIに何ができるかを、仕事ごとの地図にして、毎月更新している

どれも、作者ひとりの「好き」や「こだわり」から始まっている。そして、作者の研究ノートは、どれも同じ形で書かれている。

> **AI以前、これは何ができなかったのか（制約）→ AIが外したのは、どの制約なのか（解除）→ だから何が可能になったのか（新しい形）**

これはそのまま、「固定概念を、AIで壊す」手順になっている。たとえば、研究ノートにはこういう転換が並んでいる。

| これまでの常識 | 作者の作品で起きたこと |
|---|---|
| 物語の分岐は、書く量が多すぎて増やせない | 物語が、読んだ人を覚えていられるようになった |
| 音楽は、検索したり薦められたりするもの | 音楽を、歩いて見つける地図にした |
| 小説は小説のまま。ゲームにするのは別の大仕事 | 書き上げた物語を、すぐに声のあるゲームにできる。形を変えることが創作の一部になった |
| 店の良し悪しは「美味しい・安い・雰囲気」で測るもの | 「ひとりで入れるか」の一本の軸で、店を並べ直した |
| その場所にいるには、そこへ行くしかない | 行かなくても、その場所を見回せるようにした |
| 何を作るかは、勘で決めるもの | 誰も作っていない空白を、数えて見つけた |

**コツを教える記事は多い。自分の世界を作り、常識を壊し、その全部を公開している書き手は少ない。**読者は作品をその場で開けるので、言っていることが本当かを自分の目で確かめられる。

## 4. noteの型で

### 読者の興味（入口）
- AIの新しいニュースが毎週のように来る。追いつかなければと焦るのに、追うほど疲れる
- テクニックの記事をたくさん読んだ。でも、自分の作品や仕事は、何も変わっていない
- 「AIで何でも作れる」と言われても、何を作ればいいのかが分からない
- 心のどこかで思っている。**「自分にしか作れないものを、作ってみたい」**

### 読まなかったときの損失
- テクニックを追い続けると、新しいモデルが出るたびにゼロに戻る。自分の手元には何も積み上がらない
- 誰でも同じ道具を持つ時代に、同じ使い方をしている人は、同じものしか作れない。AIに作らせた「平均的なもの」に埋もれる
- 「ひとりではここまで」という古い物差しのまま、自分の可能性を小さく見積もり続ける

### 読んだときの利益
- 自分の「好き」や「こだわり」を、AIエージェントと一緒に、形のある世界にする道順が分かる
- 「無理だと思われてきたこと」を見つけて、壊してみる考え方が身につく
- 新しいAIが出た日に、慌てずに「自分の世界の何が良くなるか」で判断できるようになる
- テクニックを、流行としてではなく、自分の表現の道具として選べるようになる
- **連載を読み終えるころ、あなたの世界が一つ、形になっている**（各回の最後に、読者自身が手を動かすワークを置く）

## 5. 連載の構成

各回の形：

```
読者の気持ち（入口）
→ 私の世界で起きた一場面
→ 何が変わったのか（これまでの常識 → 新しい形）
→ あなたの世界に持ち帰る問いと、AIエージェントへの頼み方（ワーク）
→ 道具箱（この回で使ったテクニック。日付つきで更新）
```

| 回 | 柱 | タイトル案 | 読者のワーク |
|---|---|---|---|
| #00（無料） | — | プロは、プロンプトがうまい人ではなかった | 自分の「好き」と「こだわり」を書き出す |
| #01 | 築く | ひとりでできることの「大きさ」が変わった | 「いつか、誰かと組めたら」と思っていたことを一つ選ぶ |
| #02 | 築く | 自分だけの世界は、偏愛から始まる | 自分にしか持てない問いを一つ決める |
| #03 | 築く | 深さは、ひとつの問いを掘り続けることで生まれる | 問いを掘るために、AIに何を調べさせるかを決める |
| #04 | 築く | 速さは、手順を飛ばさなかったから出る | 最初の骨組みを、AIと一晩で作る |
| #05 | 築く | ひとつの物語を、いくつもの形で表現する | 作ったものを、別の形（声、絵、地図、ほかの言語）に広げる |
| #06 | 壊す | 「それは無理」の理由が、もう消えていないか | 自分の分野の「当たり前」を三つ書き出し、理由を疑う |
| #07 | 壊す | 常識をひとつ選んで、壊してみる | 一つを選び、AIと新しい形の試作を作る |
| #08 | 乗りこなす | 新しいAIが出た日に、何を捨てて何を残すか | 自分の世界の中で、AIの進化で良くなる所を見つける |
| #09 | 乗りこなす | 世界を、更新し続ける | 自分の世界を、毎月少しずつ育てる仕組みを作る |
| #10 | 道具箱 | テクニックは、表現の筆づかい | 自分の世界に必要な道具だけを選ぶ（プロンプト、Skill、RAG、確認の仕組み） |

**道具箱（番外・無料または安価）**
- テクニックの短い記事を、日付を入れて出し、古くなったら書き直す：プロンプト、Skill、CLAUDE.md、RAG、確認の仕組み、モデルの選び方
- 本編（考え方）と道具箱（手順）を分けることで、本編は古くならず、道具箱は常に新しくなる
- 以前に書いた有料記事（確認疲れ、思ってたのと違う）は、道具箱の回として再利用する

## 7. 書き方のきまり

- タイトル・リード・書き出しに、細かい数字を置かない（`WRITING_RULES.md`）
- 主語は「世界」と「あなた」。テクニックの名前から入らない
- 抽象論で終わらせない。各回に、作者の作品の一場面と、読者が今日手を動かせるワークを必ず置く
- 「世の中を変える」は大きな言葉なので、言い切るのは作品で起きた事実だけにする。予言はしない
- 失敗は主役にしない。越えたあとに一文で
- 道具箱の手順には、必ず日付を入れる（「2026年9月時点」）
