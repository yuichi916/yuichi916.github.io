# 書くときのきまり（連載・告知すべてに適用）

**最初に細かい数字を出さない。**

- タイトル、リード、書き出し、最初の画面（スクロールせずに見える範囲）に、細かい数字を置かない
  - ダメな例：4時間半、1,830本、12.7万字、1万9,810組、4万施設、287回、7割、326の仕事
- 入口は、読者の気持ちと場面で書く（「ひとりでは無理だと思っていたこと」「いつかやりたいこと」）
- 数字は、場面を語ったあとに、根拠として1つずつ出す。1つの段落に数字は1つまで
- 数字を並べた箇条書きで「すごさ」を見せない。すごさは、できたものの場面で見せる
- 企画書やメモでも同じ。案を出すときから、数字を先頭に置かない

このきまりは、下書きを出す前に毎回見直す。
