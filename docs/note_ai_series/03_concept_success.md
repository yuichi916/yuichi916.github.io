# 連載の軸の転換 — 失敗ではなく、「ひとりでできるようになったこと」を主役にする

> 作成: 2026-09-26 ／ 以前の案（`01_differentiation.md`・`02_voice_and_angles.md`）は失敗が主役だった。**読者が読みたいのは失敗談ではなく、「自分にも、こんなことができるようになったのか」という転換の話。**失敗と直した記録は、主役を支える「なぜ、それでも出せたのか」の側に回す。
> 数字の出典：サイトの各ページの説明文（index.html、seikai.html、hyaku.html、salon.html、hitori.html、ai-map.html、method/ の各ノート）、docs/note_seikai_full_knowhow.md、git の履歴。

## 1. 何が転換点なのか

**ひとりの人間が、5か月で、16の作品を公開した。**

- 全15話のサウンドノベル。書き上げた小説を、**4時間半で**ブラウザで遊べるゲームにした
- 声は合わせて**1,830本**、文章は**12.7万字**。物語は**7言語**で遊べる
- 短編を書き終えた**翌日に**フルボイスにし、**その翌日に**7言語へ広げた
- 手元の1,269組のアーティストから、**19,810組**の音楽の地図を作った
- 全国**40,615施設**を「ひとりで入れるか」の一つの基準で調べ直した地図を作った
- AIが何をできるかを**326の仕事**について調べ、2022年から2030年までの地図にした
- 新しいAIの発表を読んでから**約1時間で**、紹介動画を2本公開した
- 毎日のAIニュース動画を、1本**約40分**、費用ほぼゼロで作っている

作者は、声優でも、3Dの職人でも、作曲家でもない。どれも、始めたときは専門外だった。**5か月・1,354回の作業の記録が、全部残っている。**

1年前の作者には、どれもひとりでは無理な仕事だった。研究ノートにも「小説をノベルゲームにするのは数か月の仕事だった」「19,810組のアーティストを人力で分類するのは不可能だった」と書いている。それが「ひとりで数日」に入ってきた。

**これは、AIを便利な道具として使う話ではない。ひとりで作れるものの大きさが、桁で変わった話。**

## 2. 芯の一言

> **AIエージェントで、ひとりがスタジオになる。**

- 「効率化」でも「時短」でもない。**チームの仕事を、ひとりで最後まで出せる**ようになった
- 読者が持ち帰るのは、コツではなく**「自分にも、あれができるかもしれない」という見通しと、その道順**

## 3. noteの型で

### 興味 — 何に惹かれて読むのか
- 誰にでも「いつかやりたいけれど、ひとりでは無理だと思っていたこと」がある
  - 小説を書きたい、ゲームにしたい
  - 自分の店のサイトを多言語にしたい
  - 集めてきたデータを地図にしたい
  - 社内の資料を動画にしたい
- 「それ、もうひとりでできます。実際にやった記録がこれです」は、その人の心に直接届く
- 数字と実物が一緒にある（全部ブラウザで遊べる／見られる）から、嘘だと思われない

### 読まなかったときの損失
- 「AIはチャットで質問するもの」と思ったまま、使い方が止まる
- ひとりで作れるものを、外注するか、あきらめ続ける
- まわりでは、ひとりでチームの仕事を始めている人が出てきている。その差は、ツールの差ではなく「任せ方を知っているか」の差
- 新しいAIが出るたびに機能の紹介を追いかけて、自分の作りたいものは一つも完成しない

### 読んだときの利益
- 自分の「いつかやりたい」を、どの順番で、どこまでAIに任せれば形になるかが分かる
- 専門外の分野（声、絵、3D、音楽、翻訳、データ）で、どうやって「良い／悪い」を決めればいいかが分かる
- 1本を最後まで出す道順が、そのまま使える依頼文と手順で手に入る
- 速く作っても崩れない仕組みを、最初から入れられる（直した287回の記録から作ったもの）

### なぜこの連載でないといけないのか
- **完成品がある**：コツの記事は多いが、ひとりで16作品を公開し、その全部を読者が開けるものは他にない
- **全工程が残っている**：5か月・1,354回の作業の記録、研究ノート、能力の地図。作り方を、途中の判断まで含めて書ける
- **専門外で作り切っている**：エンジニアの効率化の話でも、初心者の入門でもない。「やったことのない分野で、最後まで出す」話
- **速さの内訳を正直に書く**：骨格は数日でできる。作品になるまでは数か月かかる。どちらも数字で見せる

## 4. 連載の構成（成果が主役）

各回の形：

```
できたもの（実物のリンク・数字）
→ 以前は、なぜひとりでは無理だったのか
→ AIで、何が変わったのか
→ 作り方の全部（手順・依頼文・かかった時間）
→ 人間が決めたこと（ここだけは任せなかった）
→ あなたの仕事なら、こう置き換える
```

| 回 | タイトル案（一般の読者向け） | できたもの | あなたの仕事なら |
|---|---|---|---|
| #00（無料） | AIエージェントで、ひとりがスタジオになる｜5か月で16作品を出した全記録 | 全体像 | 自分の「いつかやりたい」を1つ選ぶ |
| #01 | 小説を書き上げて、4時間半でゲームにした | 全15話のサウンドノベル | 企画書やマニュアルを、体験できる形にする |
| #02 | 声優に頼まずに、1,830本の声を入れた | 声、読み、演技 | 研修動画、読み上げ、ナレーション |
| #03 | 絵が描けない人が、3Dの世界を作った | 360°の背景、3Dの絵本 | プレゼンの図、商品の見せ方 |
| #04 | 短編を、翌日に7言語にした | 7言語のサウンドノベル | 海外向けの資料、店や会社のサイト |
| #05 | 4万施設を、ひとりで調べ直した | ひとり歓迎マップ | 市場調査、競合の一覧、根拠つきのリスト |
| #06 | 1,269組の好きな音楽から、1万9,810組の地図へ | 音楽の地図 | 手元のデータを、見える地図にする |
| #07 | 発表から1時間で、紹介動画を2本出した | 速報の動画 | 社内報、発表の要約、速報 |
| #08 | 毎日のニュース動画を、1本40分で | 1分AIニュース | 定例の報告、週報、定期の発信 |
| #09 | AIに何ができるかを、326の仕事で地図にした | 能力の地図 | 自分の業務のどこを任せるかを決める |
| #10 | 速く作っても崩れない、ひとりスタジオの回し方 | 5か月・1,354回の作業の記録 | 自分専用の「作業のきまり」を作る |

- 失敗の記録（直した287回、音が鳴らない、地図が消える）は、各回の中の「崩れなかった理由」として短く使う。主役にしない
- #10 は守りの回。直した287回の分類は、ここで「壊れない作り方」として前向きに出す

## 5. #00 の書き出し（見本）

```
この5か月で、ひとりで16の作品を公開しました。

全15話のサウンドノベルは、書き上げた小説を4時間半でゲームにしました。
声は合わせて1,830本。短編を書き終えた翌日にフルボイスにして、その翌日には7言語で遊べるようにしました。
全国4万の施設を調べ直した地図も、1万9,810組の音楽の地図も、ひとりで作っています。

私は声優でも、3Dの職人でも、作曲家でもありません。
全部、AIエージェントと一緒に作りました。

1年前の私には、どれもひとりでは無理な仕事でした。
それが今は、「ひとりで数日」に入ってきています。
AIが便利になった、という話ではありません。
ひとりで作れるものの大きさが、桁で変わりました。

この連載では、その作り方を全部書きます。
何をAIに任せて、何を自分で決めたのか。どこでつまずいて、どう越えたのか。
そして、あなたの「いつかやりたい」を、どうすれば同じように形にできるのか。
```

**書き方のきまり**
- 主語は「できたこと」。失敗は、越えたあとに1文で出す
- 数字は必ず実物と一緒に出す（リンクで遊べる）
- 「1年前の私には無理だった」は作者の実感として書き、他人やチームの作業量を勝手に見積もらない
- 速さの内訳は正直に（骨格は数日、作品になるまでは数か月）
