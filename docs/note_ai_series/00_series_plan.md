# 連載企画書 — AIエージェントのプロになる教科書

> 作成: 2026-09-26 ／ 根拠: `research/` の3ファイル、`../note_ai_era/04_note_type_analysis.md`（実在タイトル90件の分析）

## 1. コンセプト

**プロの定義**：期待どおりの成果物を、毎回、事故なく出せる人。

プロとそうでない人の差は、プロンプトの上手さではありません。「こんなはずでは」を先回りして潰せるかどうかです。

- 読者が買うもの：「こんなはずでは」が起きなくなること。業務で、そのまま使える判断と手順
- 読者が買わないもの：ツールの機能紹介（すぐ古くなり、AIが要約すれば済む）、「稼げる」話

**差別化**：根拠を次の2つに置きます。AIには一般論からは書けません。
- 著者の一次記録：AIエージェントとの16作品、326の仕事を調べた能力の地図、失敗の実例
- あるある40件：調査の数値つき

## 2. 形式（根拠つき）

| 決めたこと | 中身 | 根拠 |
|---|---|---|
| 入口は無料の「教科書」を1本 | 第0回。月1回改訂し、タイトルに【2026年9月版】と付ける | 無料の教科書を年版で改訂して入口にしている実例（梶谷健人） |
| 本編は買い切りの有料マガジン | 全10回。各回は単品でも販売 | 買い切りマガジンは、あとから足した回も購入者が読める。サブスクより始めやすい |
| マガジンの価格 | 開始時2,980円 → 5回目で3,980円 → 完結時4,980円 | 早く買った人が得をする構造にする。値上げしても既存の購入者は読める |
| 単品の価格 | 各回980円 | 実用系の上位平均は1,842円。1回5,000〜8,000字で1テーマに絞るので、その半額程度にする |
| 各回の無料部分 | 共感 → 変化の物語 → ベネフィット → 小さな価値1つ | note編集部の購入記事100件の分析 |
| 更新の頻度 | 毎週火曜、10週 | 更新の約束は守れる頻度にする（実例：毎週月曜のチャエン） |
| 情報の鮮度 | 本文は「原則と判断」。モデル名や料金は各回末尾の「最新メモ」に分け、月1回更新して日付を入れる | 「ツールを追うな」（梶谷健人）。都度更新の実例（AI駆動塾） |
| 購入者への特典 | 各回、そのまま使える実物（依頼文、CLAUDE.md の一部、チェックリスト、スクリプト） | 特典は「すぐ使える成果物」 |
| その後 | 完結後、反応を見てメンバーシップを検討する。月500円のお試し（最新メモと質問会）と、1,500円の本編 | メンバーシップ約3,000件の分析（500円お試し＋約3倍の価格差） |
| 返金 | 単品は返金可にする。マガジンは返金できないので、無料部分で目次と中身を見せる | 返金はヘルプの規定どおり |

## 3. タイトルの決まり（実データから）

- 先頭25字に、ツール名か「AIエージェント」と、読者の悩みの語を入れる（note公式の推奨15〜25字）
- 形は［ツール名］の［悩み］を［減らす／なくす］｜［条件つきの結果］
- 【】と数字は多用しない（人気の証拠がある記事では少数派）。「無料」も使わない。「…」で終わらない
- 各回の頭に「#01」などの通し番号を付けて、連載だと分かるようにする（効果のデータはないので、見分けやすさのため）

## 5. 各回の型（共通）

```
タイトル（25字以内に、ツール名と悩み）
リード 50字：誰の、何を、どう変えるか
── 無料 ──
A 共感：あるあるを、読者の言葉で
B 変化の物語：Before（自分の失敗）→ After（今のやり方で起きたこと）
原因：なぜ起きるのか（調査の数値1つ＋能力の地図か一次記録1つ）
C ベネフィット：読むとできるようになること3つ／渡すもの
小さな価値：すぐ使える1つ（1文、または判断基準）
予告：有料部分で手に入るもの（実物名で）
── 有料 ──
手順（1枚）→ そのまま使える依頼文 → 実例（直す前と後）→ やりがちな失敗 → チェックリスト
最新メモ（日付つき。モデル・機能・料金はここだけに書く）
言えないこと（限界）
次回予告（次の「こんなはずでは」を1つ、問いの形で）
```

## 6. X での運用

- 各回の公開日に、その回のあるあるを1文で出す（型①）。リンクは返信に置く。
- 間の日は、あるある40件から1つずつ出す（事故は出すが、対策は出さない）。
- 第0回の改訂日（毎月）に「今月の変化3つ」を出す。
