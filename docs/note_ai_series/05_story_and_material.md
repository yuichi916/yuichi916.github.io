## 1. 主張の骨組み — なぜ「テクニックより、自分の世界」なのか

読者を説得するには、「テクニックは古くなる」と言い切るだけでは足りない。**なぜ古くなり、なぜ世界は古くならないのか**の筋道が要る。作者の研究ノートを並べると、その筋道がすでに書かれている。

### ① AIがしていることは、いつも「一つの単価を下げる」ことだった

作者のノートは、どれも同じことを繰り返し書いている。

- 「AIが下げたのは一点だけ、『文章を用意する単価』です」（観測する物語）
- 「AIがしてくれたことは一点だけです。大量のタグ付けと、その埋め込みが自動になった」（音楽の星座）
- 「AIが外したのは『他人の時間を待つ』制約です」（1日ノベル化）
- 「AIが外したのは『大量のテキストを分類・集計する手間』です」（需要の露天掘り）
- 「場所を『建てる』コストが落ちた」（行かなくていい場所）

AIは、何かを「面白く」も「正しく」もしてくれない。**下がるのは、手間や待ち時間の値段だけ。**言葉、声、絵、調べもの、翻訳、公開。それが一つずつ安くなっていく。

### ② 値段が下がったものは、誰でも作れるようになる

安くなった作業は、誰の手にも落ちてくる。**「作れること」そのものは、もう差にならない。**

作者のノートには、「AIは物語を面白くしてはくれません。構成も、どこで泣かせるかも、人間が決めないと凡庸なものが出てきます」とある。能力の地図でも、AIがまだ苦手なこととして「独自の『声』や驚きの発明」「一次体験に基づく独自のエピソード」が挙がっている。その理由は「学習したものの平均に寄りやすいから」。

**AIに任せたままだと、誰がやっても平均に寄る。**

### ③ テクニックは、値段を下げるための工夫。だから道具に吸収されて消える

プロンプトの工夫、Skill、RAG。どれも「今のAIで、ある作業を安く・確実にする」ための工夫だ。

ところが、その工夫は次のモデルや次の機能に取り込まれていく。たとえば Claude Opus 5.5 では、考える量の既定の設定が変わり、道具の呼び出し方の一部は、前と同じ書き方ではエラーになった（公式の変更点。公開前に要確認）。**テクニックの寿命は、次のモデルが出るまで。**

### ④ 値段が下がっても残るもの — 「何を」「どの軸で」「どう渡すか」

作者のノートの結びは、どれも人間に残る仕事を名指ししている。

- 「この方法が教えてくれるのは『何が売れるか』ではありません。『どこが空いているか』だけです。そこに何を置くかは、最後まで人間の仕事です」（需要の露天掘り）
- 「情報が無いのではありません。その軸で整理されていないだけでした」（ひとり基準）
- 「大量のデータを持てるようになった時、最初に決めるべきはアルゴリズムではなく『渡し方』です」（音楽の星座）
- 「数字は方向を決めるもの。何を書きたいかは自分で決める」（需要の露天掘り）

**何を作るか。どの軸で世界を切るか。どう渡すか。**これは、AIが賢くなっても人間の側に残る。

### ⑤ しかも、世界は積み上がる。テクニックは毎回ゼロに戻る

テクニックは、新しいモデルが出るたびに覚え直しになる。自分の世界は、AIが良くなるたびに、そのまま大きくなる。**同じ物語が、声のあるゲームになり、別の言語で読めるようになり、見回せる場所になる。**AIの進化が、世界を持っている人には追い風になり、テクニックだけを持っている人には振り出しになる。

### 結論

> **AIが下げるのは「作る値段」。上げるのは「何を作るかを持っている人」の価値。**
> だから、AIエージェントのプロとは、自分だけの世界を持ち、それを深く・速く築き、表現し、常識を壊し、AIの進化ごと乗りこなせる人。
> テクニックは、その表現の筆づかい。

## 2. 歴史のたとえ（一つだけ使う）

**写真が生まれたとき、絵画に何が起きたか。**

見たものをそっくり写す仕事は、写真に置き換わった。そっくりに描く技術で勝負していた人は、居場所を失った。けれど、そこから画家は「自分にはこう見える」「自分はこう感じた」を描く方向へ向かい、絵画はかえって自由になった、とよく言われる。

**写す技術の値段が下がったとき、価値は「何を、どう見たか」に移った。**今、同じことが、文章にも、声にも、絵にも、調べものにも、一度に起きている。

（注：美術史の細部には踏み込まない。「よく語られる話として」の距離感で一度だけ使う）

## 4. 各回の題材

各回は、次の6つで組み立てる。

1. 入口の気持ち
2. 作者の場面
3. 常識 → 新しい形
4. 核の一文（作者のノートから）
5. 読者のワーク
6. 道具箱（その回で使うテクニック）

### #00 プロは、プロンプトがうまい人ではなかった（無料）
- **入口**：テクニックの記事を読むほど焦る。「自分は何を作ればいいのか」が分からない
- **場面**：この春から、AIエージェントと自分の世界を作ってきた。物語、声、見回せる場所、音楽の地図、ひとりの店の地図
- **転換**：プロの定義が「道具の使い方がうまい人」から「世界を持つ人」に変わる
- **核の一文**：AIが下げるのは作る値段。上げるのは、何を作るかを持っている人の価値
- **ワーク**：自分の「好き」「こだわり」「ずっと不満だったこと」を書き出す
- **道具箱**：なし（考え方の回）

### #01 ひとりでできることの「大きさ」が変わった（築く）
- **入口**：「いつか、誰かと組めたら」と思って、しまい込んでいる企画がある
- **場面**：小説をゲームにするのは、数か月と、たくさんの人の手配が要る仕事だった。書き上げた短編が、翌日には声のあるゲームになっていた（1日ノベル化）
- **常識 → 新しい形**：媒体を一つ選んだら、そこで終わり → 形を変えることが創作の一部になる
- **核の一文**：「これは表現の限界ではなく、手配の限界でした」
- **ワーク**：しまい込んでいる企画を一つ選び、「誰の手配が要ると思っていたか」を書く
- **道具箱**：台本をデータにする、公開の手間をなくす

### #02 自分だけの世界は、偏愛から始まる（築く）
- **入口**：自分には「世界」なんて大げさなものはない
- **場面**：ひとりで店に入るとき、本当に知りたいことに誰も答えてくれなかった（ひとり基準）。旅に行ける日が年に数日しかなかった（行かなくていい場所）
- **常識 → 新しい形**：世界は才能から生まれる → **世界は、偏愛と、ずっと抱えてきた小さな不満から生まれる**
- **核の一文**：「情報が無いのではありません。その軸で整理されていないだけでした」
- **ワーク**：自分がずっと不満だったことを一つ選び、それを「軸」の形で書く（「〇〇かどうか」）
- **道具箱**：軸を決めてからAIに調べさせる頼み方

### #03 深さは、ひとつの問いを掘り続けることで生まれる（築く）
- **入口**：AIで作ると、薄いものしかできない気がする
- **場面**：「ひとりで入れるか」を掘り続けて、全国の店を一つの軸で並べ直した。出典が食い違うことも、消さずに記録した
- **常識 → 新しい形**：正解を一つ出す → **どこまで確かなのかを見せる**
- **核の一文**：「正解を1つ出すことより、どこまで確かなのかを見せることを選びました」
- **ワーク**：自分の問いについて、AIに「反対の証拠」まで集めさせる
- **道具箱**：根拠の帳簿、出典を添えさせる頼み方

### #04 速さは、手順を飛ばさなかったから出る（築く）
- **入口**：AIで速く作ると、質が落ちるのでは
- **場面**：物語を先に完結させてから、ゲームにした。順番を守ったら、あとは機械的に進んだ。骨組みは速く、作品になるまでには時間をかけた
- **常識 → 新しい形**：速さは手抜きの結果 → **速さは、順番を守った結果**
- **核の一文**：「物語が終わっていれば、残りはすべて機械的な作業になります」
- **ワーク**：自分の企画で「先に完結させるべきもの」を一つ決め、骨組みだけをAIと一晩で作る
- **道具箱**：決めることを先に出させる頼み方（以前の #01 の依頼文を再利用）

### #05 ひとつの物語を、いくつもの形で表現する（築く）
- **入口**：一度作ったら、それで終わり
- **場面**：同じ物語が、文章になり、声になり、ゲームになり、別の言語になり、絵本の一ページになった
- **常識 → 新しい形**：作品は一つの形で完成する → **世界は、形を変えながら広がる。形を変えるたびに、新しい人に届く**
- **核の一文**：「小説を書いた人は小説の読者にしか届かない。ゲームにすれば届いたはずの人には、届かないままだった」
- **ワーク**：自分の作ったもの（仕事の資料でもよい）を、別の形に一つ変える
- **道具箱**：声・画像・翻訳の頼み方と、確かめ方

### #06 「それは無理」の理由が、もう消えていないか（壊す）
- **入口**：自分の分野では、あれは無理だと決まっている
- **場面**：物語が読んだ人を覚えていることは、誰もが夢見ていたのに、書く量の壁で誰もやっていなかった（観測する物語）
- **常識 → 新しい形**：無理なのはアイデアが足りないから → **無理だったのは、ほとんどが手配と分量の壁だった。その壁はもう下がっている**
- **核の一文**：「第四の壁は、才能ではなく設計で越えられる」
- **ワーク**：自分の分野の「当たり前」を三つ書き出し、それぞれ「なぜ無理だったのか」の理由を書く。その理由が今も有効かを、AIに調べさせる
- **道具箱**：能力の地図で「その仕事はどこまで来たか」を見る

### #07 常識をひとつ選んで、壊してみる（壊す）
- **入口**：壊すと言っても、何から始めればいいか分からない
- **場面**：推薦をやめて、音楽を地図にした。「正解を一つ出す」を「迷わせる」に変えた
- **常識 → 新しい形**：便利にする → **体験を反対向きにする**
- **核の一文**：「推薦は『正解を1つ出す』装置です。地図は『迷わせる』装置です」
- **ワーク**：#06の三つから一つを選び、「反対向きにしたらどうなるか」をAIと試作する
- **道具箱**：試作を一晩で作る手順、捨てる基準

### #08 新しいAIが出た日に、何を捨てて何を残すか（乗りこなす）
- **入口**：新しいAIが出るたびに、置いていかれる気がする
- **場面**：新しいモデルの発表を読んで、その夜のうちに紹介動画を作って出した。慌てて覚え直したのではなく、もともと持っていた作り方と確かめ方の仕組みに、新しい題材を流しただけだった
- **常識 → 新しい形**：新しいAIは、覚え直しのきっかけ → **新しいAIは、自分の世界が大きくなるきっかけ**
- **核の一文**：「完成させきることが、いちばん速い学習である」（研究ノートの入口）
- **ワーク**：次に新しいAIが出たとき、自分の世界の「どこが良くなるか」を先に書いておく
- **道具箱**：モデルの選び方、最新メモ（日付つき）

### #09 世界を、更新し続ける（乗りこなす）
- **入口**：作って公開したら、それで終わり
- **場面**：公開が一瞬で済むようになって、直すことが怖くなくなった。能力の地図は、毎月更新すると決めて公開している
- **常識 → 新しい形**：完成とは「もう直せない」こと → **完成とは「いつでも直せる」こと**
- **核の一文**：「公開が1分になると、直すことが怖くなくなる。完成の定義が『もう直せない』から『いつでも直せる』に変わります」
- **ワーク**：自分の世界を毎月少しずつ育てる予定を一つ決める
- **道具箱**：公開と確認の仕組み、壊さずに育てる作業のきまり（直してきた記録から）

### #10 テクニックは、表現の筆づかい（道具箱の回）
- **入口**：それでも、テクニックは知っておきたい
- **場面**：プロンプト、Skill、作業のきまり、確かめる仕組み。自分の世界に要るものだけを選んできた
- **常識 → 新しい形**：テクニックを集める → **世界に合わせて、筆を選ぶ**
- **核の一文**：テクニックの寿命は、次のモデルが出るまで。選ぶ目は、ずっと残る
- **ワーク**：自分の世界に必要な道具を、三つだけ選ぶ
- **道具箱**：全部の回の道具箱の一覧（日付つき）

## 5. 読者が持ちそうな反論と、答え

| 反論 | 答え | 使う場面 |
|---|---|---|
| 結局、テクニックがないと何も作れないのでは | テクニックは要る。ただし目的ではなく筆。作りたいものが決まってから覚えるほうが速い。「完成させきることが、いちばん速い学習」 | #00、#10 |
| 自分には「世界」なんて大げさなものはない | 世界は才能ではなく、偏愛と、ずっと抱えてきた小さな不満から始まる。「ひとりで入れる店が分からない」も「旅に行ける日が少ない」も、世界の種だった | #02 |
| 会社員の自分には関係ない | 仕事にも「世界」はある。自分の業界の評価の軸を一つ変える（ひとり基準のように）。外注や手配を待っていた仕事を、自分の手元に戻す | #01、#02、#06 |
| AIが作ったものに、価値はあるのか | AIが下げたのは作る値段だけ。何を作るか、どの軸で切るか、どう渡すかは人が決めている。価値はそこにある | #00、#03 |
| 速く作ると、質が落ちる | 骨組みは速い。作品になるまでは時間をかける。速さは、順番を守った結果 | #04 |
| 世の中を変えるなんて大げさだ | 世の中全体を変えると言う必要はない。自分の分野の「当たり前」を一つ外すだけで、届く人が変わる。作品で起きた事実だけを見せる | #06、#07 |

## 6. #00 の物語の運び（段落ごと）

1. **問い**：AIエージェントのプロとは、どんな人だと思いますか
2. **よくある答えと、その限界**：プロンプト、Skill、RAG。大事。でも、先月のテクニックは今月いらなくなる
3. **作者の場面**：この春から、自分の世界を作ってきた。どれも、ひとりの「好き」や「不満」から始まった
4. **気づき**：AIが下げたのは、いつも一つの値段だけだった。面白くするのも、軸を決めるのも、私だった
5. **たとえ**：写真が生まれたとき、絵画は「何をどう見たか」に向かった
6. **定義**：プロとは、自分だけの世界を、深く速く築き、表現し、常識を壊し、AIの進化ごと乗りこなせる人
7. **読者の損失**：テクニックだけを追うと、新しいモデルが出るたびに振り出しに戻る。平均に埋もれる
8. **読者の利益**：自分の世界を持つと、AIの進化が追い風になる
9. **連載の約束**：読み終えるころ、あなたの世界が一つ形になっている。最初のワーク（好き・こだわり・不満を書き出す）
10. **次回への問い**：「いつか、誰かと組めたら」と思って、しまい込んでいる企画はありませんか

## 7. 注意

- 核の一文は、作者のノートの原文をそのまま使う（言い換えない）。出典の回を編集メモに残す
- 「世の中を変える」は、予言として書かない。作者の作品で実際に起きた転換だけを、事実として見せる
- 数字は、場面を語ったあとに根拠として1つずつ（例：「その短編は、翌日には声のあるゲームになっていました」のあとに、必要なら規模を一つだけ）
