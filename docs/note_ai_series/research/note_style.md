# 人気noteの文体と、AIっぽく見える書き方（2026-09-26）

> 調べ方：WebSearch の検索結果のスニペットから（note.com は遮断されていて、本文は開けていない）。【未検証】は、元の文章を確かめられなかったもの。

## 人気noteの書き方
- スキの多い記事100本を分析した記事によると、多いのは「体験談を通じた共感」。文字数は1,500〜2,500字に集中していた（きょろ）https://note.com/kkkyoro/n/n260753000524
- note編集部の「読みやすい記事を書くための10のコツ」https://note.com/notemag/n/n0e4bc242c5b6
  - 大見出しは3〜7個
  - 1文を短く。2〜3文ごとに改行する
  - 長い記事は、図や写真を一定の間隔で挟む
- 見出し1つにつき、本文は200〜400字くらいのまとまりにする https://note.montblanc.design/n/n1fa0235f8a60
- スマホで読むとき
  - 1段落は2〜3行。4行以上は続けない
  - 1行だけの段落は、山場にだけ使う https://notematic.hatenablog.com/entry/2026/07/15/090344
- 太字は1〜2か所に絞る。note の装飾は見出しと太字しかない https://note.com/hirose_norio/n/n46698eaa71dd
- 引用のブロックは、他人の言葉か、決め台詞に使う。1〜2か所まで https://note.com/masudamegumi/n/nfc83ef6233e0
- 書き出しは具体的な一場面から。自己紹介から入らない https://note.com/personal_editor/n/n8e4c81f0dab0
- 最後に「まとめ」を作らず、気づきや余韻で終える https://odl.or.jp/2026/07/09/ai-like-japanese-writing-analysis/

## AIっぽく見える書き方
- BtoB の発注担当者110人の調査（TWOSTONE&Sons、2026年6月）https://prtimes.jp/main/html/rd/p/000000373.000015060.html
  - 90.9%が「AIで作られた」と感じた経験がある
  - 理由は「中身が薄く、調べれば分かる内容」53.6%、「整いすぎて、人の温度を感じない」46.4%
  - 約6割は、一次情報があると人間らしさを感じる
- AIらしさは、言葉づかいより構造に出る。「これから説明します → 本論 → まとめると」の報告書のような三部構成（Open Data Lab）https://odl.or.jp/2026/07/09/ai-like-japanese-writing-analysis/
- 使わない表現
  - 「〜と言えるでしょう」「重要です」「さらに」「加えて」「結論から言うと」「まとめると」
  - 太字の見出し語にコロンを付けて説明を続ける箇条書き
  - 「XではなくYだ」の連発
  https://kappa-kobuta.com/how-to-detect-ai-writing/ ／ https://mieru-ca.com/ai-seo/ai-marketing240909/
- 人間らしく書くには：語尾を散らす、文の長さを揃えない、固有名詞と具体的な場面を入れる、気持ちの動きを書く https://mieru-ca.com/ai-seo/ai_text/
