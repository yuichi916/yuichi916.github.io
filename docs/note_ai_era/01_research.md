## 0. 結論（先に5行）

1. **一般的なハウツーは、AIに要約されて終わる。** 検索のゼロクリック率は約7割に近づき、メディア各社はハウツー系への投資を減らして「独自調査・一次体験」に寄せている。
2. **note は AI 時代の追い風側にいる。** AI に引用されるドメインで国内2位（1位は YouTube）。2026年2月にレコメンドが刷新され、フォロワーが少なくてもトピック単位で届くようになった。公式に優先されるのは「人による一次情報・体験・作品」。
3. **AI分野は、note で最も伸びていて、最も疑われているジャンル。** 「テクノロジー・AI活用」の売上は大きく伸びた一方、「AIで月◯万円」系が「情報商材の巣窟」と批判された。**差がつくのは、実測・失敗・再現できる実物があるかどうか。**
4. **X では「読者も同じ目に遭っている体験」と「実物」が伸び、「自分の作品の紹介」は伸びない。** 公開コードの重みは返信・引用が5.0、いいねが0.5で、ブックマークの重みは存在しない。本文リンクは、コード上は減点されないが、実測では不利。
5. **だから有料記事は「一次体験の読み物」＋「読者が自分のエージェントに貼れる実物」の二層で作る。** 要約されても、実物（規約ファイル・テンプレ・スクリプト）は要約で代わりがきかない。

### 1-5. 無料部分に何を置くか（note編集部の分析）

- **購入されたビジネス・IT系記事100件**（[notemag 2025年5月](https://note.com/notemag/n/nb51c6c55f1ac)）の無料部分には、次の3つが入っていた。
  - (A) 読者の悩みへの共感・問いかけ
  - (B) 体験や Before/After による変化の物語
  - (C) 読んで得られるものの明示
- **購入された有料記事500件のタイトル**（[notemag](https://note.com/notemag/n/n367ec637ae54)）の共通点は「具体性・メリットの明確さ・トレンド性」。
- → ユーザーが最初に示した型（興味 → 自分ごと化 → 放置コスト → 変化 → 方向性 → 有料で具体策）と一致する。**型そのものは正しい。AI時代に足すべきものは §4 に書く。**

### 1-6. AI分野の有料記事への批判

- 2026年1月、有料記事の上位に「AIに執筆丸投げで月5万円」のようなテンプレ記事が並ぶことを指摘する投稿が拡散した（[X トレンド](https://x.com/i/trending/2010358549172642068) ／ [Togetter](https://togetter.com/li/2650739)）。
- 「Claude Code は情報商材屋にうってつけ」という論考も出ている（[note](https://note.com/kbito/n/ndcac70fc2152)）。
- **批判される型**
  - 「月◯万円」を約束する
  - AI の出力をそのまま並べただけ
  - 「note で稼ぐ方法を note で売る」という自己言及
  - 無料部分で煽って、有料部分が薄い
- **評価される型**
  - 本人の一次情報・実測・失敗談がある
  - 再現できる手順やコードがある
  - 価値を「稼ぐ」ではなく「成果物・業務改善」で示している

## 2. X — 何が伸び、何が伸びないか

### 2-1. 公開コード（xai-org/x-algorithm, `home-mixer/params/param.rs`）

調査エージェントが 2026-09-24 版を直接確認した。自分のノート [A-10 Xの測り方](../../method/x-no-hakarikata.html)（2026-09-20）とも一致している。

| 行動 | 重み |
|---|---|
| リンクコピーでの共有 | 20.0 |
| リプライ／引用／DM共有 | 5.0 |
| 著者をフォロー | 4.0 |
| リポスト | 1.0 |
| いいね | 0.5 |
| リンクを開く | +0.2（減点ではない） |
| 通報／ミュート／興味なし／ブロック | −234 ／ −58.8 ／ −43.2 ／ −31.2 |

- 重みは「件数」ではなく「予測確率」に掛かる。「通報1件＝いいね468件」という読み方は、コード内のコメントが名指しで誤りとしている。
- **ブックマークの重みは存在しない。**「ブックマークはいいねの10倍」は誤り。
- 48時間を超えたポストは候補から外れる。フォロワー1,000人以下の小さなアカウントには新規の後押しがある。
- 相互フォロー間のリプライにブーストがかかる。2026年7月に20から15へ下げられた（[docs](https://github.com/xai-org/x-algorithm/blob/main/docs/BIDIRECTIONAL_BOOST_CHANGE.md)）。

### 2-2. 外部リンク

- 公式の見解：プロダクト責任者の Bier は、リンクを減点したことは一度もなく、リンクをリプ欄に貼る必要はもう無いと述べている（[2026-04-08](https://x.com/nikitabier/status/2041911302541730237) ／ [2026-07-28](https://x.com/nikitabier/status/2082217171506344297)）。
- 実測では不利が続いている。
  - Buffer：無料アカウントのリンク付きポストのエンゲージメント中央値は0%（[Buffer](https://buffer.com/resources/links-on-x/)）。
  - 自分のノート：同じ記事で、本文にリンクを置いた投稿が4,034インプ、返信に置いた投稿が30,184インプ（7.5倍）。
- **運用**：本文だけで価値が完結するように書き、リンクは自分への返信に置く。ただしこれは「公式がやめてよいと言った」ことと矛盾するので、自分のアカウントでA/Bテストして決める。

### 2-3. 伸びる型（自分のノート A-10、実例44件より）

| 型 | 根拠 |
|---|---|
| ① 現場で起きた理不尽を一文で、飾らずに書く | 界隈の20件中9件がこの型。8,700いいね・63万インプの投稿は、メディアも数字も無かった |
| ② 動くものを15秒で見せ、作り方を本文に全部書く | プロンプト全文を置いた投稿は、いいね919に対して保存1,087 |
| ③ 自分の設定ファイルなどの実物をそのまま晒す | 公式発表の紹介が1,100いいね、個人の CLAUDE.md が2,291いいね |
| ④ 速報を日本語2行に圧縮して最速で出す | 英語の原投稿が500いいねに対し、日本語2行版が2,000いいね |
| ⑤ 立場を取り、反論を歓迎する | いいね247・引用124で33万インプ |

- **伸びないもの**
  - 自分の作品の紹介：最大でも100万表示・1,500いいね。フォロワー数に依存する。
  - 「リンクに一言添えただけ」：100投稿の記録で、42投稿が反応ゼロだった。
  - 15〜20本の長大スレッド。
- **層によって正解が逆になる**
  - 一般層に届いた14件は、全件に画像か動画があった。
  - AI・開発者界隈で伸びた投稿は、55%がテキストのみだった。

### 2-4. 2026年に変わったこと

- Grok による自動翻訳がタイムラインに出るようになった（2026年3月、[Impress Watch](https://www.watch.impress.co.jp/docs/news/2097609.html)）。**英語の速報を訳すだけの価値は下がった。**型④は「圧縮」と「日本の文脈」を足さないと効かない。
- AI で自動返信する4.2万アカウントが削除された（2026年7月、[Bier](https://x.com/nikitabier/status/2080747924380856519)）。大半は「AIについての思想リーダー風スロップ」だった。
- 収益化が「Original Content Rewards」に置き換わり、転載や寄せ集めは対象外になった（2026年9月、[TechCrunch](https://techcrunch.com/2026/08/08/x-replaces-misaligned-revenue-sharing-program-with-original-content-rewards/)）。
- 「AI驚き屋」（「ヤバすぎる」「神」）への批判が定着している（[ITmedia](https://www.itmedia.co.jp/aiplus/article/2603/30/1260330033/)）。

## 3. AIエージェント時代の「読む・払う」

### 3-1. クリックが減っている

- Pew（2025年7月）：AI 要約が出た検索でリンクがクリックされたのは8%。出なかった検索では15%（[Pew](https://www.pewresearch.org/short-reads/2025/07/22/google-users-are-less-likely-to-click-on-links-when-an-ai-summary-appears-in-the-results/)）。
- SparkToro（2026年6月）：米国の Google 検索のうち68.01%がクリックなしで終わった（[SparkToro](https://sparktoro.com/blog/in-2026-less-than-one-third-of-google-searches-still-send-a-click/)）。
- 検索からの流入は、2年間で小規模パブリッシャーが−60%、大規模は−22%（[SEJ](https://www.searchenginejournal.com/search-referral-traffic-down-60-for-small-publishers-data-shows/569959/)）。**個人の書き手ほど打撃が大きい。**
- メディア幹部の投資意向（「増やす」から「減らす」を引いた値）（[Nieman Lab](https://www.niemanlab.org/2026/01/publishers-prepare-to-be-squeezed-by-ai-and-creators-in-2026/)）
  - 増やす：独自調査 +91、文脈・解説 +82、人間の物語 +72
  - 減らす：ハウツー −42、エバーグリーン −32

### 3-2. 信頼と支払い

- Reuters DNR 2025：完全にAIが作ったニュースに抵抗が無い人は12%。人間主体でAIが補助する場合は43%（[Reuters Institute](https://reutersinstitute.politics.ox.ac.uk/digital-news-report/2025/dnr-executive-summary)）。
- Pangram × YouGov（2026年4月）：69%が、AIの文章を人間の文章より信頼していない（[Pangram](https://www.pangram.com/blog/ai-sentiment-survey)）。
- 「人間が書いた記事なら高く払う」は、実験の結果が割れていて決定的ではない（[The Conversation](https://theconversation.com/people-say-they-prefer-stories-written-by-humans-over-ai-generated-works-yet-new-study-suggests-thats-not-quite-true-251347)）。**「人間が書いた」だけでは売りにならない。売りになるのは中身の一次性。**
- Ben Thompson「Content and Community」：コンテンツはコモディティになった。これからは、コンテンツを核にコミュニティを作る側に価値がある（[Stratechery](https://stratechery.com/2025/content-and-community/)）。

### 3-3. 読者が今困っていること（AIエージェント）

- Stack Overflow 2025：最大の不満は「ほぼ正しいが、正しくない」で66%。AIの正確さを信頼しない人は46%（[SO Survey](https://survey.stackoverflow.co/2025/ai)）。
- METR（2025年）：経験のある開発者は、自分では20%速くなったと感じていたが、実測では19%遅くなっていた（[METR](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/)）。
- Zenn で人気の話題：Codex と Claude Code の比較、個人の設定ファイルの公開、「テストを握り潰して完了と報告する」問題（[Zenn](https://zenn.dev/jissokulog/articles/498e691f7f287d)）。
- Qiita：AI関連記事は 9,123件（2024年）から 18,779件（2025年）に増え、「AIを使う」から「AIと作る」へ移っている（[Qiita](https://corp.qiita.com/releases/2026/04/trend-announcement/)）。
- 非エンジニアが Claude Code で業務を作る記事が大量に出ている。**ただし、作ったものを自分で監査できないリスクがある**（[Retool](https://retool.com/blog/vibe-coding-risks)）。
- Agent Skills（SKILL.md）が公開標準になり、Codex・Cursor・Gemini CLI なども対応した（[The New Stack](https://thenewstack.io/agent-skills-anthropics-next-bid-to-define-ai-standards/)）。**「エージェントに読ませるファイル」を読者に渡す形式が、ツールをまたいで通用するようになった。**

### 3-4. GEO の小技は効かない

- Google は2026年5月の公式ガイドで「AEO/GEO も SEO と同じ」とし、llms.txt などの専用ファイルは不要とした（[Google](https://developers.google.com/search/blog/2026/05/a-new-resource-for-optimizing)）。
- llms.txt の97%は一度もリクエストされていない（[Ahrefs](https://ahrefs.com/blog/llmstxt-study/)）。
- → 小技より、**日付・数字・一次体験を本文にはっきり書く**方が効く。

## 4. 統合 — 読まれる × 買われる記事の条件

ユーザーが示した型（**興味 → 自分ごと化 → 放置コスト → 変化 → 方向性 → 有料で具体策**）は、note編集部の分析とも一致していて、骨格として正しい。
AIエージェント時代には、次の5つを足す。

| # | 足すもの | 理由 |
|---|---|---|
| 1 | **冒頭の3行に、その人しか持っていない数字を置く** | 一般論の冒頭はAIでも書ける。AIに要約されても残るのは固有の数字（例：「161本が無音のまま」） |
| 2 | **予告は「何が手に入るか」を実物名で書く** | 読者は記事をAIに貼って要約させ、買うか決める。要約されたときに「規約ファイル全文」「スクリプト3本」と実物名が残れば、購入の理由も残る |
| 3 | **有料部分は「読む層」と「貼る層」の二層にする** | 読む層は判断・失敗・理由。貼る層は、読者が自分のエージェントに渡せる規約・テンプレ・コード。後者は要約では代わりがきかない |
| 4 | **限界と「向いていない人」を書く** | 情報商材への批判と対照になる。返金可にして、信頼を先に払う |
| 5 | **稼ぐ話をしない** | AI分野で批判されている型の筆頭。価値は「事故が減る」「捨てずに済む」で示す |

| A-6 質問の解像度 | 16作品。規模の宣言、1問ずつの質問、承認の門、4つの検問 |
| A-7 自動テストの実際 | 事故を止めた7つの検査。コードつき |

| C-2 速報動画 | 人間の指示3つ、根拠台帳26件、別エージェントの審査9回 |

### テーマ候補の比較

| 候補 | 読者の痛み | 一次性 | 貼れる実物 | 批判リスク | 判定 |
