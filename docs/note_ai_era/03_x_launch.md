# X 告知プラン — 有料記事「文面を読まずに『投稿して』と打った」

> 根拠: 自分の研究ノート [A-10 Xの測り方](../../method/x-no-hakarikata.html)（公開コード17項目・実例44件）と `01_research.md` §2
> 原則:
> 1. 作品や記事の紹介を主題にしない。**読者も同じ目に遭っている体験**と、**実物**を出す。
> 2. 本文だけで価値が完結するように書く。記事のリンクは自分への返信に置く（実測で7.5倍の差）。
> 3. いいねより、返信・引用（重み5.0）と共有（20.0）を呼ぶ形にする。煽ると、ミュート（−58.8）や興味なし（−43.2）の予測が上がる。
> 4. 各ポストは加重280字以内（無料アカウントでも折りたたまれない長さ）。
> 5. 記事の主張は「最後に人間が目で確認、をやめる」。この逆張りを、公開前の数本で少しずつ出す。

## 1. 公開前（6日前から。リンクは貼らない）

### D-6　型③＋実物：自分の地図の数字を出す
```
326の仕事で、AIがどこまで来たかを地図にしてる。
テストコードを書く力は「専門家並み」。自分が書いたコードの正しさを確かめる力は「補助」止まり。
エージェントの「完了しました」が当てにならないのは、この差のせいだと思う。
```
- 画像は ai-map.html の該当マス2つ（テスト生成＝4、セルフレビュー＝2）を並べたスクショ。
- 地図のURLは返信に置く（地図は無料なので、ここは置いてよい）。

### D-5　型①：現場のぼやきを一文で
```
改稿したら、音声161本が数週間ずっと無音のまま公開されてた。
エラーは一度も出てない。字幕は正しく出てた。声だけ無かった。
```
- テキストのみ。解説も教訓も付けない。

### D-4　型⑤：立場を取って、反論を歓迎する
```
「AIの出力は最後に人間が確認」は、任せる量が増えるほど効かなくなると思ってる。
エージェントの間違いは、たいてい「ほぼ正しい」形で出てくるので。ほぼ正しいものは、目をすり抜ける。
```
- 反論が来たら、その日のうちに全部返す。相互フォロー間のリプライにはブーストがかかる。
- 反論のうち良いものは、記事の追記の材料にする。

### D-3　型①：機械をすり抜けた誤りを一つ
```
AIに書かせた投稿文に「捏造があれば不合格のテストで、他の2モデルは1本も通らなかった」とあった。
数字も引用も原文どおり。照合も通った。
でも原文は、落ちた理由を書いてない。並べただけで「捏造した」と読める文になってた。
```

### D-2　型③：実物をそのまま晒す（画像1枚＋一行）
```
AIエージェントに毎回読ませている作業規約の一部。全部、踏んだ事故から1行ずつ増えた。
```
- 画像は、規約の「2. 完了は観測で言う」と「4. 妥協を隠さない」の2節だけを切り出す。全文は有料部分に置く。
- 最初の1枚はXの一覧でサムネを兼ねるので、文字が読める大きさにする。

### D-1　型①をもう1本
```
翻訳ファイルのデプロイを忘れたら、多言語版が全部「完璧な日本語」で表示された。
安全なフォールバックを書いたせいで、エラーが1個も出なかった。
```

## 2. 公開日

### 本告知（リンクは返信に置く）
```
Opus 5.5 の紹介動画を出したとき、最終の文面を読まずに「投稿して」と打った。
それでも公開前に誤りが6件止まってた。見つけたのは私じゃなく、事実の確認だけを任せた別のエージェント。

「最後に人間が目で確認」をやめて、人間の仕事を2つに絞ったやり方を書きました。
```
- 画像は記事の見出し画像（黒い画面に「投稿して」の一行）。
- **自分への返信**に、次の文とリンクを置く。
```
無料部分に、機械の照合をすり抜ける誤りの3つの型を置いています。
有料部分は、そのまま打てる依頼文4つ・スクリプト3本・エージェントに読ませる規約の全文です。
（note URL）
```
- note の **SNSプロモーション機能** を ON にする。記事をXで紹介してくれた読者は、割引価格で買える。

### 同じ日に、有料部分の依頼文1だけを単独で出す（4つのうち1つを見本として）
```
AIに何か頼むとき、最初に必ずこれを打っている。

「この作業で私が決めないといけないことを、重要な順に5つ挙げて。それぞれ選択肢と、選択が結果に与える違いも書いて」
```
- リンクは付けない。保存・共有されることを狙う形（型②の変形）。

## 3. 公開後（7日間）：記事に出てくる事故を1日1件

記事に出てくる事故は、そのまま型①のポストになる。**事故は出すが、対策（依頼文・スクリプト・規約）は出さない。**

| 日 | 本文（例） |
|---|---|
| +1 | 「病だった」を合成音声が「びょうだった」と読んでた。書き起こして文字で比べるテストは緑。漢字に戻すと、どっちで読んでも「病」になるから。 |
| +2 | AIの審査で点数がいちばん高かった投稿文の切り口で出したら、いちばん読まれなかった。1行目が細かい話から入ってた。 |
| +3 | エージェントの作業記録には「全方位を密な建物で囲む閉塞感」とあった。やったことは合ってる。床が一面のっぺりしていることは、書いてなかった。 |
| +4 | 数字の照合器に、わざと誤りを6つ混ぜた。5つは捕まった。「出力が40%速い」だけ素通りした。40%は、別の文脈（費用）で原文にあったから。 |
| +5 | 3Dの背景を、2日半で同じ場所を6回作り直した。「背景が真っ黒」以外の言葉を持ってなかった。 |
| +6 | 数字も引用も合ってるのに、文として間違ってる。AIに書かせた文章のこれ、型が3つしかなかった。 |
| +7 | 翻訳ファイルのデプロイを忘れたら、多言語版が全部「完璧な日本語」で表示された。エラーは1個も出なかった。 |

- 3日に1回くらい、その日の失敗の投稿に「この形の失敗をまとめた記事」として、返信でリンクを置く。毎日は置かない。
- 読者から「自分もこうなった」という返信が来たら、許可をもらって記事の追記に入れる（記事末尾の約束どおり）。

## 4. やらないこと

- 「【保存版】」「【完全版】」「ヤバすぎる」「〇〇は終わった」
  - 実例44件中、【速報】【驚愕】系は2件しかなかった。
  - AI驚き屋への批判が定着していて、煽りはミュートの予測を上げる。
- リンクに一言添えただけのポスト。記録では100投稿中42投稿が反応ゼロで、その全部がこの形だった。
- 15本を超える長いスレッド。続けて投稿するなら3〜6本まで。
- 投稿時刻の最適化に時間を使うこと。効果はほぼ無いという監査がある。
- 「〇部売れました」「月〇万円」。AI分野の有料noteで最も批判されている型。

## 5. 測るもの（2週間）

| 指標 | 見る場所 | 何を判断するか |
|---|---|---|
| ポストごとのインプ・返信・引用 | X アナリティクス | どの型が届くか（型①・③・⑤の比較） |
| リンクを返信に置いた場合と本文に置いた場合 | 同じ告知を別の日に1回ずつ | 公式は「リプ欄に貼る必要はもう無い」と言っているが、自分のアカウントで確かめる |
| 記事の閲覧数 → 購入数 | note のダッシュボード | 無料部分の購入率。低ければ「予告」を具体化する |
| 流入元（X／検索／note内） | note のダッシュボード | 2026年2月にレコメンドが刷新されたので、note内の流入がどれくらいあるか |

**取れなかった数字は、0ではなく「取得できなかった」と書く。**（規約4と同じ）
