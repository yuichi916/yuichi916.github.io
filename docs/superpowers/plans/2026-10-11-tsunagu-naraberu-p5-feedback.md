# 『つなぐ×ならべる』クオリティアップ 第5部: 遊んでみての指摘への対応

依頼主の指摘（2026-10-11）:
1. つなぐ派の方が不利に見える
2. セリフが棒読み。もっと工夫して
3. つなぐ派の操作と見た目を、もっと本家（落ち物の連鎖パズル）のように
4. ならべる派のアクティブ連鎖で、間に挟むときに連打するとおかしくなる
5. おじゃまを消すときの演出がもっと欲しい

## 4. 連打の不具合（原因と直し方）
- 原因: 入れ替えの先行入力（落下中・浮遊中に押した入れ替えを最大6刻み試し続ける）が、カーソルが離れたあとも、押したときと違うパネルが来たあとも成立していた。ランダム操作2000盤で、先行入力1,501回のうち357回がカーソルから離れた所、322回が別のパネルで起きていた。さらに入れ替えの演出は「今のカーソル位置」に描いていたので、見えている所と実際に入れ替わった所がずれた。
- 直し方: 先行入力は「カーソルが同じ位置のまま」「押したときの2枚がその位置にいる」ときだけ成立。入れ替えの合図に位置を持たせ、演出はその位置に描く。→ 0回／0回。

## 1. つなぐ派が不利に見える（測った事実）
- 段を互い違いにした総当たり（各200試合）で、格上が勝つ割合は両派でほぼ対称。差は**負けるまでの時間**: 格下のつなぐ派は30秒前後で埋まり、格下のならべる派は1分半粘る。人はたいてい CPU より格下なので、つなぐ派で遊ぶと押しつぶされて見える。
- 負け方を追うと、つなぐ派は1〜5個の少量のおじゃまが組を置くたびに降り続け、色のつながりが分断されて連鎖が組めなくなっていた（1回に降る上限を30→18にしても結果は同じ＝大量に降って死んでいるのではない）。
- ならべる派のおじゃまは「3マス以上たまってから・予告が出て3秒たってから」降るが、つなぐ派には待ちがなかった（ルールの非対称）。
- 対応: つなぐ派にも「予告が出てから tsunaguLandSec 秒は降らない」を入れ、総当たりと全段2000試合で測り直す。

## 2. 声
- いまの声は turbo_v2_5 を安定寄りで使っていて、ひなた「ひなたスペシャル」の声の高さの幅が3.8半音しかなかった。
- eleven_v3 ＋ 感情の指示（キャラの性格×台詞の種類、連鎖は段が上がるほど大きく）で作り直す。1本4テイクから「書き起こしが台詞と一致（0.7以上）」の中で抑揚の大きいものを選ぶ。
- 連鎖の掛け声を、段が上がるほど技名らしく盛り上がる言い回しに書き直す。
- 連鎖の掛け声と勝ち負けの声は前の声を切って鳴らす（以前は前の声が終わるまで鳴らさず、長い声だと2連鎖目以降が鳴らなかった）。

## 3. つなぐ派の操作と見た目
- NEXT 枠（次の組を大きく、その次を小さく）と点数、連鎖中の点数の式（消した数×10 × ボーナス）を盤の横に。
- 連鎖の数を、消えた場所に出す。
- 予告アイコンを 小つぶ1・大つぶ6・岩30・星180・月360・冠720 に。待ちが明けたら跳ねて知らせる。
- 上から降るおじゃまが、置く時間のうちに着地して見えるように初速をつける。
- 負けたら盤のつぶが崩れ落ちる。

## 5. おじゃま消しの演出
- つなぐ派: 一緒に消えるおじゃまに印（盤が先に知る）。消える演出の間、白く点滅・震え・ひびが広がる。消える瞬間に灰色のかけら・ほこりの輪・割れる音。6個以上で「ブレイク！」。
- ならべる派: 解凍の始まりに合図。ブロックが揺れて下の段にひびが走り、ほこりが舞い、割れる音。1マスずつ裏返るように出て、かけらと音。幅4以上を消し切ったら「ブレイク！」。
