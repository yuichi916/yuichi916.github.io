## 1. 目的
ユーザーの既作長編小説 **「正解の外側 ～すべての正解が視える俺が、答えのない少女と世界を変えるまで～」（全15話・第一部完結・計416KB）** を、**KitBash3D Future Slums 2 の退廃近未来スラム世界観**で、フル演出のサウンドノベル（Web ADV）として全編再現する。まず**第1話を縦スライス**として完成度MAXで作り、世界観・品質・エンジンを確定してから2話以降を量産する。

## 6. エンジン（SoundNovelEngine / seikai.html 単一ファイル）
cabin の StoryEngine を発展させた汎用サウンドノベル基盤。
- **画面**: 全画面背景(scene bg, クロスフェード)＋左右/中央の立ち絵(表情差分・登場/退場・発話ハイライト)＋下部テキストボックス(話者名＋本文, 1文送り, オート, 既読スキップ, ログ)＋場面カード(第N話/場面名)＋分岐選択肢。
- **台本データ**: `SCRIPT = { ep1: { title, scenes:[ {id, bg, bgm, se?, beats:[Beat...] } ] } }`。Beat: `{say:'kai'|'rin'|'haha'|'narr'|'you', text, expr?}` / `{bg:'...'}`(背景変更) / `{bgm:'...'}` / `{se:'...'}` / `{choose:[{label,reply,ending?}]}` / `{sceneCard:{no,name,sub}}` / `{fx:'...'}` / `{end}`。
- **キャラ**: `CHARS={kai:{name:'カイ',color},rin:{name:'リーン',color},haha:{name:'母',color}}`。立ち絵 `assets/seikai/cg-<char>-<expr>.png`。
- **機能**: 背景クロスフェード、立ち絵の登場/退場スライド＋発話時ふわり、テキスト1文送り(クリック/Space)、オート再生、既読管理＋スキップ、バックログ、章(話)セレクト＋セーブ(localStorage `seikai_save`)、分岐/複数エンド、`prefers-reduced-motion`配慮。
- **音**: BGMクロスフェード＋SE(WebAudio or audio要素)。
- **i18n**: 当面日本語のみ（原作日本語）。

## 8. 脚色方針
- 原作の地の文・会話を**最大限そのまま活かす**(ユーザー自著)。段落=ナレーション beat、「」=話者 beat に分解。話者は文脈で判定(「母は言った」等の地の文手がかり、話者明示が無い所は前後で推定)。
- `---`=場面転換(背景/BGM切替)、`［　今　］`等=場面カード。長い地の文は数 beat に分割し読みやすく。
- 演出付与: 崩落=画面シェイク＋SE、力の発動=光の線fx、回想=セピア/ヴィネット。
- **改変は最小限**(表示上の分割・演出のみ)。分岐エンドは後半話で原作の分岐点に選択肢を足す形(正史は保持)。
