# 設計仕様 — 心を整える没入世界トップ再設計

- **日付**: 2026-06-18
- **対象**: `index.html`（トップ）を中心に、`niwa.html` / `cabin.html` の周遊動線
- **目的**: コンテンツ増加に対する整理、誘導バナーの統一、流入数とリピートの向上

---

## 1. コンセプト

サイトの**メインコンテンツ＝「心を整える没入3D世界」**。
**瞑想小屋(cabin)から始まり、浮遊島の世界(niwa)を歩いて各コンテンツを巡る／世界に浸って心を整える**、という体験を背骨に据える。

新聞ジャーナル（Views Engineer Journal）とゲーム集という従来の2軸は後退させ、
没入できる癒しの世界を主役にする。ただし以下を**両立**させる（ユーザー決定）:

- **ハイブリッド**: SEO・流入のためテキストのホームは残しつつ、最上部を「世界への入口」ゲートウェイにする。note/ジャーナルは下層の支えに。
- **ブランドは世界観に溶かし込む**: 「Views Engineer / AI解説・ずんだもんAIラボ」は正面に出さず、note/AI解説を「本の宇宙・読む」として世界の一部（月光の書架）に組み込む。`Views Engineer` は世界の"庭師/著者"署名として小さく残す（既存読者・SEO継続のため）。

## 2. 現状の問題点（再設計の根拠）

- **ナビ過密**: 13リンク（Featured/Manifesto/Directory/About + 一人旅/小屋/客間/浮遊島/立体数独/将棋ぷよ/島の地図/ストップウォッチ/TOEIC News/TOEIC模試/note）。
- **数字の不整合**: ヒーロー・Directory見出し・stamps が「5つの場所 / Channels 5+」のまま。実際は10コンテンツ以上。
- **バナーが継ぎ足し構造**: cabin CTA / hitoritabi CTA / niwa(№08) / sudoku(№09) / 将棋ぷよ(№10) が様式バラバラに縦積み。

- **世界が主役になっていない**: 没入世界の土台は `niwa.html` に既存（後述）だが、トップはそれを主役化していない。
- **周遊が片方向**: `cabin.html` も `niwa.html` も戻り先が `index.html` のみ。世界内の回遊が閉じていない。
- **世界のポータル欠落**: niwa の各シーンは note/音楽宇宙/一人旅/ストップウォッチ/小屋/島の地図/TOEIC模試/瞑想部屋へ繋がるが、**🧊立体数独・♟将棋ぷよ・📚TOEIC News・lingo が世界に繋がっていない**。

## 5. リピート／流入を上げる具体策

1. **世界そのものが回遊エンジン**: 小屋→世界→各所、を1訪問で複数巡れる動線にする（pages/session 向上）。
2. **今日の一手**: 立体数独のデイリー＋ストリークを「世界の地図」に [デイリー] バッジ付きで常設し、再訪動機を作る。
3. **[NEW]/[更新] バッジ**: 新規・更新コンテンツ（立体数独・将棋ぷよ等）を再訪者が一目で発見。
4. **周遊の閉路化（Phase 2）**: 各コンテンツページ末尾／戻りリンクを `index.html` だけでなく `niwa.html`（世界）へも向け、世界に戻って次の場所へ行ける。
5. **流入(SEO)維持**: テキストのホーム・structured data・stopwatch/TOEIC等の単体SEOページは温存。世界化は上層に重ねるだけで、クロール可能テキストを削らない。

## 6. スコープと段階

### Phase 0（バックアップ・最初に実施）
- **現 `index.html` を丸ごと `journal.html` として保存**（新聞版＝Views Engineer Journal）。内容は一切変えず複製。
- 新トップから `journal.html` へリンクでたどれるようにする（フッター ＋「読む／本の宇宙」節の末尾あたりに「新聞版（旧トップ）を読む →」リンク）。
- `journal.html` 内の自己参照（canonical / og:url / 内部アンカー）は新URLに合わせて最小限調整。ナビの `HOME` 等は新トップ(index.html)へ戻す。

### Phase 1（コア・今回の主対象）
`index.html` のフル再構成:
- 世界ゲートウェイ Hero（§4①）
- 統一「世界の地図」カードグリッド（§4②）＝バナー統一＋全コンテンツ整理
- 本の宇宙/読む・外の窓・About・Closer の世界観トーン化（§4③〜⑥）
- ナビ圧縮、数字不整合の全修正（§4）
- リピート施策のうち [デイリー]/[NEW] バッジ表示（§5-2,3）

### Phase 2（世界の周遊配線）
- `cabin.html` に「庭へ出る → niwa.html」出口を追加（小屋→世界の正規動線）。
- `niwa.html` のポータルに **立体数独・将棋ぷよ・TOEIC News・lingo** を追加（既存シーンへの割当て or 既存セルの portal 追記。新規3Dジオメトリは作らない）。
- 主要コンテンツページに「← 庭にもどる(niwa)」の戻りリンクを追加し周遊を閉路化。

### Phase 3（任意・重）
- 立体数独・将棋ぷよ専用の新規 niwa シーン（3Dジオラマ）を `memory/niwa-composition-rules.md` の構図ルールに沿って制作。ユーザー希望時のみ。

- **現トップが `journal.html` としてそのまま残り、新トップからリンクで到達できる**（内容は無改変、自己参照のみ最小調整）。
- トップ最上部が「瞑想小屋から始める／世界を歩く」のゲートウェイになっている。
