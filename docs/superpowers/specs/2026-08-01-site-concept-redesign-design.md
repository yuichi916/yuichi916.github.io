# サイト全体コンセプト刷新 設計

対象: `https://yuichi916.github.io/`（`index.html`）
決定日: 2026-08-01

## 1. 背景と問題

トップの看板は「A QUIET GARDEN — 心を整える庭」で、焚き火小屋 → 浮遊島という没入導線が骨格になっている。
しかし実際の中身は、この看板から大きくはみ出している。

| 層 | 該当 | 状態 |
|---|---|---|
| A 心を整える庭（癒し） | 森の小屋・浮遊島・灯し火 | いまの看板 |
| B 世界と物語を作る | 正解の外側（全15話）・とびだす絵本・音楽の宇宙 | 最も活発だが看板に無い |
| C AIで作る／実用ツール | journal・TOEIC・ストップウォッチ・lingo | 世界観の外。TOEICは2026-05から更新停止 |

`正解の外側` は残酷描写ありのダークSFで「癒し」と真逆。実用ツールはそもそも世界観に入らない。
**看板が当てはまるのはAだけ**という状態が続いていた。

## 2. 決定した軸

ユーザー選択:

1. サイトの軸 = **AIで作る人（制作記が主役）**
2. 作品の扱い = **二本立て（作品棚と制作記棚）**
3. トップの骨格 = **看板を差し替え、骨格は活かす**

## 3. コンセプト

> **ひとりぶんの手で、どこまで作れるか。**
> `ONE PERSON, WITH AI`

「AIで作る」を前面に出すと、無数にある「AI活用」の棚に埋もれる。この場所の特異点は
**ツールではなく到達量**にある。ひとりで、普通は届かない規模に届いている。

- **作品棚** = 到達したものの証拠
- **制作記棚** = どうやって届いたかの手順

二本立ての弱点（何の場所か分からなくなる）は、この「証拠と手順」の関係で塞ぐ。
どちらの棚も同じ主張の裏表になる。
