# 異世界立体数独「ルーン・キューブ」 設計ドキュメント

- 日付: 2026-06-14
- 配置: `yuichi916.github.io` の子ページ `sudoku.html`（index.html №09 カード）
- 流儀: niwa/cabin/salon と同じ **単一HTMLファイル + CDN ライブラリ + localStorage**、ビルド不要

## 1. ゲームのコア

- **形状**: 宙に浮く N×N×N の魔法キューブ。N=3/4/5 を難易度として選択。
- **ルール（ラテンキューブ）**: X・Y・Z の3軸すべてで、各ライン（軸に平行な N 個のセル並び、計 3·N² ライン）に同じ記号がちょうど1回ずつ。
  - 重複が出たラインは赤く脈動して即時フィードバック。
- **記号**: 属性ルーン（炎/水/風/地/雷… N 種、色分け付き）。設定で数字 1〜N 表示に切替可能。
- **盤面生成**:
  1. 完全解を `cell(i,j,k) = (i + j + k) mod N` を基にしたラテンキューブで生成（必要に応じ行・記号の置換でシャッフル）。
  2. セルを1つずつ抜きながら、バックトラック・ソルバで**一意解が保たれる**間だけ削除を続ける。
  3. 難易度 = N（盤サイズ） + 公開セル比率。3=初級/4=中級/5=上級。
- **クリア判定**: 全セル充填かつ全ライン制約を満たす。

## 2. 3D操作性 UX（最重要）

立体数独の宿命「奥のセルが見えない・押しにくい」を4段構えで解決する。

| 機構 | 内容 |
|---|---|
| 自由回転＋微回転 | ドラッグで全方向回転、放置でゆっくり自転、ホイール/ピンチでズーム。 |
| レイヤースライス | サイドのスライダーで1層だけ抽出 → 他層はゴースト（半透明）化、抽出層が正面を向き「ほぼ平面の N×N」として読める。X/Y/Z 軸切替可。 |
| エクスプロード表示 | ボタンで層を分離展開し全セルを一望。 |
| 選択ガイド | セル選択でそのX/Y/Z の3ラインが発光、同記号セルも強調、矛盾ラインは赤脈動 → 立体制約を直感的に把握。 |

- **入力**: セルをクリック → 周囲にルーン放射パレット（PC）/ 画面下ボトムシート（モバイル）。長押し/右クリックで候補メモ（ペンシルマーク）。
- **ヒント**: 限定回数の「魔法の導き」で正解セルを1つ開示（★評価に影響）。
- **セル表現**: 空セル=半透明ガラスブロック、充填セル=発光するルーンクリスタル、固定ヒント=別色枠。

## 3. はまり要素（リプレイ性）

- **デイリーパズル**（日付シード）＋ 🔥連続記録ストリーク。
- **タイマー / ベストタイム / ★評価**（ミス数・ヒント数で星を算定）。
- **世界解放プログレッション**: クリアで次の異世界スキンを解放。KitBash 各キット = 報酬。
  `闇のファンタジー → エンチャント → ヴァルハラ → トレジャーアイランド`
- **実績バッジ＋XP/レベル**（salon と同系統）。
- **localStorage** で中断再開・記録・解放状態・設定を保存。
- 結果シェア用テキスト生成。

## 6. 想定モジュール分割（単一ファイル内の論理ユニット）

- `LatinCube`: 解生成・一意性ソルバ・パズル生成（純ロジック、UI非依存）。
- `CubeView`: Three.js シーン/セルメッシュ/回転/スライス/エクスプロード/レイキャスト。
- `InputPalette`: ルーン選択 UI（PC放射 / モバイルボトムシート）・候補メモ。
- `GameState`: タイマー・ミス・ヒント・★算定・クリア判定・localStorage 永続化。
- `Progression`: 世界解放・実績・XP・デイリー/ストリーク。
- `WorldTheme`: 背景/プラットフォーム切替（アセット参照）。

## 7. 非対象（YAGNI）

- マルチプレイ・オンラインランキング。
- 6面ルービック型や729マスタワー型（別形状は将来別ページ）。
- キューブ N>5。
