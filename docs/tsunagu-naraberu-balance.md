# 『つなぐ×ならべる』バランス測定（2026-10-06）

測定ツール: `node _dev/tsunagu-naraberu/balance.mjs --games 2000`（CPU対CPU、worker_threads 26並列）。
半数の試合でつなぐ派を左（1P）に置き、左右の偏りを打ち消している。勝率の幅は Wilson の95%信頼区間。

先攻・後攻やシードによる偏りがないことの確認用。

目標（spec 1章）との照合:
- 勝率 45〜55%: **3段とも達成**
- 平均試合時間 2.5〜4分: やさしい・ふつうは達成。**つよいは約1分で未達**。
  - つよい同士は攻撃が速く、どのつまみでも1分前後に収まった。
  - 全段共通の変換率で延ばすと、やさしいが10分の打ち切りに近づくため、見送った。

## 調整の経緯（効いた順）

1. **つなぐ派を4色に**。5色では、攻撃なしでもつなぐ派CPU（ふつう）の54%が自滅した（盤が散らかり、4連結が作れない）。
2. **ならべる派CPUに「次の1手で何連鎖か」の見込みを入れた**。
   - 以前は消せる所をすぐ消していたため、1試合で送るダメージが約40しかなかった。
   - その差を変換率で埋めると、たまの連鎖が一撃必殺になり、試合が開幕で決まっていた。
   - 改善後は、変換率が穏当な値で五分になった。
3. **CPUの速さを人間並みに**。つよいが毎秒4手を打ち、試合が6秒で終わっていた。
4. **ならべる派の初期盤から「1手で2連鎖・2手で3連鎖」を除いた**。積まれた盤で始まる側だけが開幕で一撃を撃てる問題への対処。
5. **開幕ウォームアップ**。それでも、つよいでは空盤のつなぐ派が10秒台で倒される試合が38%あった。両派に同じく効く倍率で抑えた。

## 既知の限界

- 五分になっているのは「このCPU同士」での話。人間同士では派の得意不得意がずれる可能性がある。そのためのハンデ設定（1段±20%）を付けている。
- つよいの下位10%は15秒前後で決着する。開幕の速攻は完全には消えていない。
