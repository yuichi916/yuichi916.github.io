## 調整の経緯（効いた順）

1. **つなぐ派を4色に**。5色では、攻撃なしでもつなぐ派CPU（ふつう）の54%が自滅した（盤が散らかり、4連結が作れない）。
2. **ならべる派CPUに「次の1手で何連鎖か」の見込みを入れた**。
   - 以前は消せる所をすぐ消していたため、1試合で送るダメージが約40しかなかった。
   - その差を変換率で埋めると、たまの連鎖が一撃必殺になり、試合が開幕で決まっていた。
   - 改善後は、変換率が穏当な値で五分になった。
3. **CPUの速さを人間並みに**。つよいが毎秒4手を打ち、試合が6秒で終わっていた。
4. **ならべる派の初期盤から「1手で2連鎖・2手で3連鎖」を除いた**。積まれた盤で始まる側だけが開幕で一撃を撃てる問題への対処。
5. **開幕ウォームアップ**。それでも、つよいでは空盤のつなぐ派が10秒台で倒される試合が38%あった。両派に同じく効く倍率で抑えた。

## 2026-10-09 アクティブ連鎖・天井の猶予の追加
- 入れた直後は、やさしい39% / ふつう62% / つよい73% と段ごとに逆向きへずれた。
  - ならべる派CPUが、浮いている・落ちているパネルがあるあいだ手を止めていた → 動かせるパネルは動かすように変更。
  - 停止時間のあいだ手動のせり上げも止まり、材料が来なかった → 原作どおり、せり上げボタンで停止を打ち切れるように変更。
  - これで ふつう・つよい は五分に戻った。やさしいだけ猶予と停止時間が効きすぎたので、つなぐ派やさしいの発火基準を2連鎖に上げた。

## 2026-10-10 消える演出（光る→顔→1枚ずつ）とおじゃまの1マスずつの変化
- 消える時間が数に応じて延びた（3枚 0.9→1.35秒）。ならべる派の連鎖が遅くなり、ふつう・つよいでつなぐ派57.5%に。
- convT を 0.73→0.85、つなぐ派やさしいのぶれを 3→1 にして、48.3 / 49.4 / 49.9% に戻した。

## 2026-10-11 CPU5段（かんたん・おにを追加）と全段の合わせ込み
- 5段にした直後: かんたん28.7% / やさしい48.2% / ふつう49.5% / つよい48.4% / おに77.6%。20秒以内の決着は つよい31.5%・おに16.3%。
- 早い決着の中身を見ると、負けは全部つなぐ派だった。
  - つよいのつなぐ派はぶれ10で積み方が雑になり、10秒台で詰まっていた → ぶれ2・発火基準2に。
  - それでも残ったのは、ならべる派の積まれた盤からの偶然の連鎖が、空の盤から始まるつなぐ派に刺さる型。開幕を「40秒で0.25→1」から「60秒で0.05→1」に弱めて5%未満に。
- 開幕を弱めると、おにのつなぐ派は83%まで上がった。ならべる派CPUのほうを強めようとして、次を試したが効かなかった。
  - 速さ（1操作4→2刻み）: 83.5%。
  - 読みの幅（候補25→60）、見込みの重み、2手目の重み: 84〜91%。
  - 積む高さ7→9段: 51.7%で五分になるが、20秒以内の決着が19%に増える。高く積むと序盤に偶然の8〜10連鎖が出るだけで、中盤以降は押し負けている。
  - 積む高さを時間で上げる: 92%。上の「偶然の連鎖」が消えると、ならべる派CPUは中盤に勝てない。
- 結論: このCPUの強さの差は、ならべる派CPUが連鎖を「狙って」組めないことから来る。つなぐ派CPUは毎回3〜5連鎖を組めるが、ならべる派CPUは小さな消しが中心で、送るダメージが少ない（おにで1試合あたり つなぐ派301・ならべる派63）。
- そこで、対戦パズルで一般的な「段ごとのCPUの攻撃補正」を入れた（人が操作する側にはかからない）。そのままかけると序盤の瞬殺が増えたので、開幕のウォームアップと同じ60秒で満額にしている。
- かんたんは逆に、つなぐ派CPUが連鎖を組めず28.7%だったので、つなぐ派側に×1.75。

## 2026-10-11 第5部: 遊んでみての指摘（つなぐ派が不利に見える）
- 段を互い違いにした総当たりで、格上が勝つ割合は両派でほぼ対称だった。差は負けるまでの時間（格下のつなぐ派は30秒前後で埋まる）。
- 負け方を追うと、つなぐ派は1〜5個の少量のおじゃまが組を置くたびに降り続け、色のつながりが分断されて連鎖が組めなくなっていた
  （負け試合で平均37個、最大連鎖0〜2）。1回の上限を30→18・24にしても結果は同じ＝大量に降って死んでいるのではない。
- ならべる派は「予告が出て3秒たってから」降るのに、つなぐ派には待ちがなかった。つなぐ派にも同じ3秒の待ちを入れた（2秒・5秒も測り、3秒が最も効いた）。
  格下側の勝率: つなぐ派 18/2/11/16% → 23/2/11/16%、ならべる派 31/4/16/19% → 27/1/12/13%（ほぼ対称に）。
- 待ちでつなぐ派が強くなった分、convT を 0.85→0.95（ルール側）、かんたんのつなぐ派補正 1.75→1.9、ふつうのならべる派補正 ×1.1 で戻した。
- 人対CPUの測り方（`--human`）を足した。上の「人対CPU」の表。

## 既知の限界

- 五分になっているのは「このCPU同士」での話。人間同士では派の得意不得意がずれる可能性がある。そのためのハンデ設定（1段±20%）を付けている。
- つよい・おにの下位10%は30秒前後で決着する。開幕の速攻は5%未満まで減ったが、ゼロではない。
- 人対CPUで、格下のつなぐ派が早く崩れる差は残っている（上の「人対CPU」）。
- CPUの攻撃補正はCPUの手の質の差を埋めるもの。ならべる派CPUが連鎖を狙って組めるようになれば、補正は小さくできる。
