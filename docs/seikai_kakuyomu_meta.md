## 2. 紹介文（そのまま貼る）

```
「正解が視える」というのは、間違える自由がない、ということだ。

地下世界アビスの最底辺、第五層「廃棄層」。
番号だけで呼ばれる少年カイには、誰にも言えない力があった。
目的を定めれば、そこへ至る最善の道筋が、金色の線となって視える。
母を喪った日に手に入れた、生き延びるための唯一の武器。

便利だと思うだろう。俺もそう思っていた。三年前までは。

ある日、記憶を持たない少女リーンが廃棄層に送られてくる。
夢を見ない。涙が出ない。初めて会ったはずのカイの名前を、言い当てる。

そして——彼女だけが、カイの道筋に映らなかった。

だがカイの道筋は、リーンを排除した未来に「何もない」と告げる。
リーンがいない道は、行き止まり。
リーンがいる道だけが、どこまでも続いている。

道が視える少年と、道を持たない少女。
二人は地上を目指す。空を見るために。

──これを書いている今、君はもういない。
いや、正しくは、まだいない。

　＊

全15話・完結済。

本作は、フルボイス・360°背景の「サウンドノベル版」もブラウザで無料公開しています。
インストール不要、リンクを開くだけで遊べます。
https://yuichi916.github.io/seikai.html
```

**変更点**: 冒頭を宣伝から**主題の一行**に差し替え、リンクを末尾へ移動。
一覧・検索・SNSカードに出る先頭3行が、作品の顔になる。
