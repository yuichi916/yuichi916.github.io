# 「正解の外側」普及戦略

作成: 2026-07 / 対象: https://yuichi916.github.io/seikai.html（ブラウザ・サウンドノベル）

## 0. 前提：蔵書43,000冊の解析からわかった「人が惹かれる要素」

books-universe のクラスタ解析（和書ラノベ・文芸中心）で、実データとして突出していた需要軸：

| 軸 | 蔵書での強さ | 「正解の外側」での対応 |
|----|----|----|
| **恋慕（恋愛・情愛）** | 圧倒的最大。数十クラスタに分散 | カイ×リーン。**最大の集客レバー**として感情の機微を強化中 |
| **喪失×救済のカタルシス** | 「夏へのトンネル」「半分の月」「STEINS;GATE」型が根強い | ノノの喪失／未来のカイがリーンを再構築する手紙＝時間遡行的救済 |
| **廃墟・ディストピア** | 廃墟クラスタ2つで計971冊 | 地下世界アビス第五層・廃棄層（3D没入背景で実装済） |
| **謎（引き）** | 複数クラスタ | リーンの正体・母・地上の真実・「なぜ名前を知っている」 |
| **冷たい主人公のギャップ** | 恋慕クラスタの鉄板 | カイ「冷たさは防具」→ 亀裂が覗く瞬間 |

**結論**: 世界観（廃墟）と謎は既に強い。**恋慕＝最大の未回収レバー**。ここを丁寧に描くほど大衆性が上がる。次章の脚本強化はこの方針。

## 1. 作品側の強化（プロダクト＝普及の土台）

普及の前に「人に見せて離脱されない」状態を作る。

### 1-1. カイの深掘り（実施済 / ep1）
- **身体化した癖（ライトモチーフ）**: ノノを握った右手が無意識に「空」の字をなぞる。全編の伏線として反復。
- **wants/needs の明示**: want=地上に出る/二度と間違えない。need=「必要としてしまう恐怖」を手放す勇気。
- **能動的な感情回避**: 「視てしまえば救いたくなる。救えば失うのが怖くなる。だから最初から誰も持たない」——罪悪感を選択として言語化。
- **恋慕の芽**: リーンがカイの指の癖を見抜き、二人が同じ「空」を知っていたと気づく。「悲しみか、生まれて初めての別の何か」。

### 1-2. 冒頭90秒の「引き」最適化（次の打ち手）
離脱は最初の1〜2分で決まる。**謎＋恋慕＋喪失を90秒以内に提示**する導線を維持・磨く。手紙（未来のカイ→リーン再構築）は謎＋恋慕の複合フックとして優秀。

### 1-3. シェア・回遊の仕掛け
- OGP画像・タイトル（SNSカードで映る名シーン＋惹句）
- 「あなたはどの選択をした？」分岐のシェア文言
- タイトル画面の明確なCTA、感想導線（マシュマロ/フォーム）
- モバイル最適化・セーブ・続き再生（実装済）

## 2. 配信チャネル（ROI順）

### Tier 1 —— 即・低コスト・高ROI

**A. 小説投稿サイトで原作を連載 → プレイ版へ誘導（最重要ファネル）**
- **カクヨム**／**小説家になろう**／**ノベルアップ+** に「正解の外側」本文を連載。
- 恋慕×喪失×ディストピアは、なろう/カクヨム読者層に直撃。
- 各話末に固定文で「▶ 声・音楽・背景つきサウンドノベル版はこちら」リンク。
- **既に本文があるので転記のみ**。読者ゼロからの集客をプラットフォームに肩代わりさせる。

**B. フリーゲーム／ノベルゲーム投稿サイト登録**
- **ふりーむ！**（freem.ne.jp）— 最大級。ブラウザ作品OK。
- **PLiCy**（plicy.net）— ブラウザゲーム特化・スマホ対応必須（済）。
- ノベルゲーム好きが「探しに来る」場所に置く。掲載＝受動的な発見を得る。

**C. X（@ViewsEngineer）**
- 縦型トレーラー 15-30s（名シーン＋惹句＋URL）。
- 名台詞スクショ＋引用（恋慕・喪失の刺さる一節）。
- タグ: #フリーゲーム #ノベルゲーム #サウンドノベル #インディーゲーム
- 制作の裏側（AI活用）も別軸で発信。

### Tier 2 —— 中コスト・資産化

**D. YouTube（ずんだもんAIラボ）**
- シネマティックPV 60-90s（背景3D＋ボイス＋BGM＋惹句）。
- または「AIと本格サウンドノベルを作った」解説回。チャンネルのAI軸と合致。
- 概要欄・固定コメントにプレイURL。

**E. note（開発日誌・世界観）**
- 「AIと二人で長編サウンドノベルを作った話」「廃墟を3Dで没入させる技術」「キャラに深みを出す方法」。
- AI/創作クラスタに刺さる。Amazonアソシエイト（viewsengineer-22）で関連書籍リンク収益化。

**F. pixiv**
- カイ・リーン立ち絵、名シーン差分。キャプションにプレイリンク。イラスト経由流入。

### Tier 3 —— 拡張（余力があれば）
- **itch.io**（英語UI版）— 海外VNファン。i18nは既存パターンで拡張。
- **Steam**（無料 or 少額）— 長編化した場合の受け皿。将来検討。

## 3. 実行順ロードマップ

1. **今週**: カイ深掘り反映（済）→ 冒頭90秒の引き確認 → OGP/シェア文言整備。
2. **来週**: カクヨム連載開始（第一話〜）＋各話末に誘導リンク。ふりーむ／PLiCy登録。
3. **その次**: X縦PV投下 → note開発記1本 → pixiv差分。
4. **反応を見て**: YouTube PV、itch.io英語版。

**KPI**: プレイ開始数・完走率（離脱ポイント）・カクヨム→プレイ版の遷移率。数字を見て1-2章を磨く。
