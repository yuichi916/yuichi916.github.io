## 1. AIエージェント能力アトラス 2026

**作品名**
```
AIエージェント能力アトラス 2026 — 326の仕事で「できる・できない」を数えた地図
```

**概要（一覧に出る短文）**
```
AIエージェントに何が頼めるのかを、ベンチマークの点数ではなく実際の仕事326件で数え直し、2022年から2030年まで海岸線が動く一枚の地図にしました。全マスに根拠リンクつき。
```

**カテゴリ**
```
データサイエンス / AI / BOT、アプリケーション
```

**本文**
```
「結局いま、AIに何が頼めるのか」を知りたくて作りました。

ベンチマークのスコアは上がり続けますが、それが自分の仕事のどこに効くのかは分かりません。そこで、点数ではなく実際の仕事そのものを数えることにしました。

8つの領域から326の仕事を取り出し、それぞれを「専門家と比べてどこまでか」の6段階で色分けしています。2022年から2030年（予測）まで時間軸を動かすと、AIができる範囲＝陸地の海岸線がせり上がっていくのが見えます。

■ 分かったこと（2026年9月時点）
・326件のうち 71% が実務品質以上
・32% が専門家並み以上
・まだ届いていない「海」は 4%

■ 作り方
評価は印象ではなく、公開されている一次情報に紐づけています。全マスに根拠リンクを張ってあり、どの判断がどの資料から来たのかを辿れます。根拠として読んだ原典は626本。手作業の集計ではなく、スクリプトで走査して集計・再生成できる形にしてあります。

■ 記事
測り方そのものについては Qiita にも書きました。
https://qiita.com/kernel_yu/items/1c7447e935a2ca2d718d
```

## 2. Salon des Sons — 19,810アーティストの音楽宇宙

**作品名**
```
Salon des Sons — 19,810アーティストを星座にした音楽地図
```

**概要**
```
検索しないで音楽を探す。1,269アーティストの個人コレクションを起点に、19,810作家×42,744の関連を一枚のWebGL地図に広げました。星を押すと、知らない曲が鳴ります。
```

**カテゴリ**
```
アプリケーション、データサイエンス / AI / BOT
```

**本文**
```
サブスクのおすすめに飽きた夜のために作りました。

推薦をやめて、地図にしています。自分の個人コレクション1,269アーティストを種にして、Last.fm・Wikipedia・MusicBrainz の類似性で 19,810作家 × 42,744関連まで広げ、それを星座のように並べたWebGLの宇宙です。

■ 使い方
・星を押すと、そのアーティストの曲が鳴ります
・名前を知らなくてもいい。サイコロを一回押すだけでも旅になります
・好きな曲の「隣」を辿ると、知らない音楽に出会えます

■ 作り方
類似度からレイアウトを計算し、14の銀河にクラスタリングしています。描画は WebGL。データは 7.6MB の JSON 一枚で、サーバー側の処理はありません。ブラウザだけで動きます。

制作の記録は note に書きました。
https://note.com/views_of_life/n/n12fe7a1ff494
```

## 3. ひとり歓迎マップ

**作品名**
```
ひとり歓迎マップ — 「ひとりで入れるか」を根拠つきで探す全国地図
```

**概要**
```
ひとりで入れる店を、雰囲気ではなく根拠で探す地図です。全国40,615施設のうち3,277件は公式情報で裏が取れています。出典と、出典同士の食い違いもそのまま見せます。
```

**カテゴリ**
```
アプリケーション、位置情報
```

**本文**
```
「ひとりで入っていいのか分からない」を、雰囲気ではなく観測できる事実で解こうとした地図です。

全国 40,615 施設を「ひとりで入れるか」という一本の軸で並べ直しました。そのうち 3,277 件は、店の公式情報で裏が取れています。残りは個人の訪問記や地図データが根拠で、詳細画面では ● 公式 / ◐ 公式以外 と分けて表示します。

■ ひとりチェック 6項目
カウンター席があるか / 一人客の利用実績が確認できるか / 予約なしで入れるか / コース強制ではないか / チェーンではない独立店か / 周辺に同業が少ない穴場か。この6つを信号機の色で出します。

■ 三つの決めごと
1. 店の自己申告に頼らず、観測できる属性から組み立てる
2. 混雑は測れないので、周辺に同業が少ない独立店を「穴場候補」の代理指標にする
3. 事実には出典・URL・公式かどうかを必ず添え、出典同士の食い違いは消さずに両方見せる

■ データ
施設データは OpenStreetMap (ODbL)、地図タイルは国土地理院、人口は Wikidata と令和2年国勢調査。47都道府県を収録しています。

作り方はこちらに。
https://yuichi916.github.io/method/hitori-kijun.html
```

## 4. lingo — YouTubeで英語リスニング

**作品名**
```
lingo — YouTubeに英日字幕を重ねて聴くリスニング学習ツール
```

**概要**
```
YouTubeのURLを貼るだけで、英語字幕と日本語訳を同時に表示。読み終わった行が自動で消えるので、文字ではなく音に集中できます。登録不要・無料。
```

**カテゴリ**
```
アプリケーション、教育
```

**本文**
```
英語字幕を出すと、目で読んでしまって耳が育たない。日本語字幕を出すと、英語を聴かなくなる。その両方を避けたくて作りました。

YouTube の動画を貼るか、検索するだけで、英語字幕と日本語訳を同時に表示します。特徴は「読み終わった単語や行が自動で消える」ことです。文字が消えていくので、最後は音で追うしかなくなります。

■ できること
・英日字幕の同時表示
・区間リピート（聞き取れない数秒だけを繰り返す）
・単語をクリックして辞書を引く
・読み終わった行のフェードアウト

■ 作り方
字幕は YouTube の timedtext を使っています。Android 版は WebView で署名つきリクエストを横取りする形で作り直しました（github.com/yuichi916/lingo-android）。

紹介記事はこちら。
https://note.com/views_of_life/n/nbaf453125fec
```

```
https://yuichi916.github.io/lingo.html
```

