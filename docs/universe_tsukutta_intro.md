## キャッチコピー（100字以内）
19,810人のアーティストが14の銀河になった音楽地図。星をクリックして、知らない名曲との出会いを宇宙散歩。

## 説明
音楽を「検索する」のではなく「出会う」ためのWebGLアプリです。19,810人のアーティストを14ジャンルの銀河に配置し、42,744本の“似ている”関連でつないだ音楽の宇宙地図。

- 星（アーティスト）をクリック → その場で **YouTube試聴** ＋ おすすめアルバム
- **★お気に入り** と **巡った軌跡（来歴）** を記録、端末間で移行も
- **サイコロ** でランダムな出会い、**ジャンル銀河**で気分から探索
- 8ステップのガイドツアー付き、スマホ最適化、常駐ミニプレーヤー

インストール不要・ブラウザだけ・無料。知らないジャンルへ一歩踏み出すための、音楽発見アトラスです。
