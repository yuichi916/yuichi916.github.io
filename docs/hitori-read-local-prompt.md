# ひとり歓迎マップ — 手元の本文から、ひとりチェック6項目を読む

**ページの取得は済んでいます。** BATCH_FILE の各施設には `pages[].path`（ローカルの本文ファイル）が
入っています。その**ファイルを Read して**読んでください。Web には取りに行かないこと。

## 目的
「その施設に、ひとりで行って、店内で過ごせるか」だけを読み取ります。
持ち帰り・宅配・通販・催事・法人向けの記述は、どれだけ具体的でも**採りません**。

## 読み取る6項目（書いてあるものだけ）
1. `solo_ok` — その施設について「一人利用・おひとり様・ソロ・1名・お一人でも」に触れた記述（原文）
2. 席 — `counter_seats`(カウンター席の記述、または席数の整数) / `seats_total`(店内の総席数, 整数)
3. `payment_method` — **店内での支払い**: ticket_machine / cash_only / cashless_ok / counter_person
4. `reservation` — **席・入店・利用枠の予約**: none / possible / required
   **採らない**: 弁当・テイクアウト・持ち帰り・受け取り・デリバリー・出前・通販・宿泊の予約
5. `silence` — posted（「お静かに」「黙浴」「私語はお控えください」など静けさを求める案内）
   / observed（中で静かに過ごせることに触れた記述）
   ※「静かな景色」「落ち着いた雰囲気」のような立地・内装の宣伝文句は採らない
6. `access` — public / residents_only / members_only / male_only / female_only
   ※「期間限定」「会員ポイント」のような販促の語は利用条件ではない

## 併せて拾う（あれば）
`hours`(原文) / `closed_days`(原文) / `price`(整数・円) / `parking`(原文)
`status` は **今の状態が書いてある時だけ**（「当面の間休業」「閉店いたしました」）。
日付つきの過去の告知（「8月12日(水)臨時休業のお知らせ」）は**採らない**。

## いちばん大事な約束 — 引用は書き写さず、**行番号で指す**
Read はファイルを `   12	カウンター8席をご用意` の形（行番号 + タブ + 本文）で返します。
根拠にした行の**行番号だけ**を `line` に書いてください。引用文そのものは書かないこと。
（書き写すと表記が変わり、機械照合で弾かれて捨てられます。行番号ならその心配がありません。）

根拠にできる行が無い事実は出力しない。推測で語彙を当てはめない
（「券売機」と書いていなければ ticket_machine にしない）。

## 出力
各事実は {"k":..., "v":..., "line":<行番号>, "url":"<そのページの url>"}。
OUT_FILE に Write:
{"results":[{"id":..,"name":..,"status":"ok","identity":"match","facts":[...],"note":"<1行>"}]}
何も取れなかった施設は results に入れなくてよい。

## あなたが自分でやること
**サブエージェントを起動しない。** ファイルを自分で Read し、自分で OUT_FILE を Write する。

## 最終回答（3行だけ）
1行目: `facilities=<n> facts=<n> signals=<6項目に該当した数>`
2行目: OUT_FILE のパス
3行目: 気づいたこと1行

## 補足（行番号の指し方）
- 1つの事実につき1行。複数行にまたがる根拠なら、いちばん中心の行を指す
- `url` は、その行が載っていたページの url（pages[] の該当する方）
