# ひとり歓迎マップ 拡充 — 「ひとりチェック6項目」狙い撃ち抽出

公式ページに**書いてある事実だけ**を抜く。推測・要約・一般論・創作は禁止。
書いていないことは「書いていない」と返すのが正解であり、埋めるのは誤り。

**この抽出の目的はただ一つ「その施設に、ひとりで行って、店内で過ごせるか」**である。
持ち帰り・宅配・通販・催事・法人向けの記述は、どれだけ具体的でも**採らない**。

## 狙う6項目（この順で探す。他の情報は付け足さない）
1. `solo_ok` — その施設について「一人利用・おひとり様・ソロ・1名・お一人でも」に触れた記述（原文）
2. 席 — `counter_seats`(カウンター席の記述または席数) / `seats_total`(店内の総席数, 整数)
3. `payment_method` — **店内での支払い**が次のどれか1つ: ticket_machine(券売機) / cash_only(現金のみ) / cashless_ok(カード・電子マネー可) / counter_person(レジで支払い)
4. `reservation` — **席・入店・利用枠の予約**が次のどれか1つ: none(予約不要と明記) / possible(予約できる) / required(要予約・完全予約制)
5. `silence` — 次のどれか1つ:
   posted(「お静かに」「黙浴」「私語はお控えください」など、**静かに過ごすことを求める案内**がある)
   observed(**中で静かに過ごせること**に触れた記述。例「カウンターで黙々と」「一人で静かに読書できます」)
   ※「静かな景色」「落ち着いた雰囲気」「喧騒を忘れる立地」など**立地や内装の宣伝文句は採らない**
   （中で黙って居られるかとは別の話であり、ひとりで行く判断の役に立たない）
6. `access` — public(誰でも可と明記) / residents_only(住民限定) / members_only(会員制) / male_only(男性専用) / female_only(女性専用)

### reservation の判定を誤らないこと（重要）
**採る**: 「ご予約は電話にて」「席のご予約」「WEB予約で入店」「完全予約制」「予約不要でご利用いただけます」
**採らない**（これらは席の予約ではない）: 弁当・テイクアウト・お持ち帰り・受け取り・デリバリー・出前・通販・EC・ケータリング・宴会コースのみの予約、
「◯◯ネットで注文」「待たずに受け取れる」。**迷ったら採らない。**

### payment_method も同じ
テイクアウト専用の決済手段しか書かれていない場合は採らない。店内利用の支払いに読めるものだけ。

## 併せて拾う（あれば）
`hours`(営業時間, 原文) / `closed_days`(定休日, 原文) / `price`(整数・円) / `status`(open|closed_temporarily|closed_permanently ※告知がある時のみ) / `parking`(原文)

## 手順（web 取得は1施設あたり最大3回）
1. `web` のドメインが tabelog.com / sauna-ikitai.com / retty.me / instagram.com / x.com / twitter.com / facebook.com / goope.jp なら **取得せず** status="non_official_url"。
2. `web` を取得。失敗したら1回だけ再試行（http→https、www 有無、末尾スラッシュ）。それでも駄目なら status="fetch_failed"。
3. トップに6項目が無ければ「ご利用案内 / 料金 / よくある質問 / 店舗情報 / メニュー / 施設案内」らしきリンクを**1つだけ**追加取得する。
4. 施設名照合: ページの施設名が入力 name と同一か。
   **チェーンの全社サイトで、この店舗の個別ページに辿り着けなかった場合は identity="unclear"**（全社共通の記述を、その店舗の事実として扱わない）。
   別店舗・別会社なら identity="mismatch"（事実は返さない）。

## 禁止
- 語彙値の当てはめを推測でやらない。「券売機」と書いていなければ ticket_machine にしない。
- 「一般にサウナは…」のような一般論を solo_ok にしない。**その施設について書かれた文だけ**。
- 引用(quote)が取れない事実は出力しない。quote は必ず**取得したページの原文そのまま**（要約・言い換え禁止）。
