QIITA TECH MAP

Qiita で書かれる技術は、
4年でどう変わったか。

Qiita API v2 で、2022年10月（ChatGPT 公開の前の月）から2026年9月までの48か月について、各月8日〜14日の1週間に投稿された記事を全部（合計 105,160 本）集め、タグを地図にしました。点の大きさは、その週にそのタグで書いた人の割合です（陸は、書いた人が少ないタグでも島として見えるよう、最低の大きさを付けています）。再生ボタンで4年が動き、タグにさわるとその推移が出ます。

AI のタグ（AI・生成AI・LLM・ClaudeCode・ChatGPT など17個）を1つでも付けて書いた人は、2022年10月の 1.2% から、2026年9月には 34.9% になりました。

地図の「生成AI・エージェント」の地域（Security や GoogleCloud なども入っています）は、4.1% から 38.5% に広がりました。

いちばん伸びたタグは「AI」、いちばん縮んだタグは「JavaScript」でした（最初の半年と最後の半年の平均で比べています）。

    この地図の作り方

    • データ: Qiita API v2 の /api/v2/items。各月8日〜14日に投稿された記事を全部取りました（月の頭は年末年始や大型連休に当たるため、8日から）。
    • 物差し: その週にそのタグで書いた人の数 ÷ その週に書いた人の数。記事の数だと、ひとりの連投で大きく見えてしまうためです。
    • タグは大文字・小文字をまとめました。タグが「tech」1つだけの記事（ほかのタグと一度も一緒に付かない短い記事の群れ）は外しています。
    • 地域: 4年分を合わせて、同じ記事に一緒に付いた回数からタグどうしの近さを出し、Louvain 法で分けました。地域の名前は筆者が付けています。
    • 配置は4年分で一度だけ決めて固定しています。陸は円を合わせた形（小さなタグも島として見えるよう、最低の大きさを足しています）、国境はパワー図（円の大きさを考えたボロノイ図）の線です。
    • 限界: 1か月を1週間で代表させています。12月はアドベントカレンダーの時期で、話題が偏ります。タグは書いた人が自分で付けたものです。
