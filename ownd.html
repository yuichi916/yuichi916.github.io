Ameba Ownd の終了（2027年3月31日 11時）への備え

Ameba Ownd の写真を、消さずに引っ越す無料・非公式の道具です

Ameba Ownd の書き出しファイルには、写真そのものが入っていません。入っているのは写真の置き場所（アドレス）だけで、サービスが終わると写真も見られなくなります。書き出したファイルをここに入れると、写真をぜんぶパソコンに保存し、無料で公開できるホームページ一式と読むための保存版を作ります。

見て分かる案内: 書き出しから公開までの手順の動画（6分50秒） ・ この道具で作った見本のサイト（架空の喫茶店）

このページは個人が作った非公式の道具です。サイバーエージェント（Ameba Ownd の運営）とは関係がありません。Ameba Ownd についてのお問い合わせは、公式のサービス終了のお知らせとヘルプをご覧ください。

パソコンで開いてください。Ameba Ownd の書き出しはパソコンの管理画面でしかできません。この道具も、写真をたくさん保存するのでパソコン（Chrome か Edge）向けです。このページのアドレスを自分に送っておくと便利です。

    3無料で公開する
    
    
    できた「公開用」フォルダ（zip のときは「…_公開用.zip」）を、無料の置き場に入れるだけで公開できます。どちらも無料で独自ドメインが使えます。
    
    
    おすすめ：Cloudflare Pages
    
    
    ファイル数の上限がはっきりしていて（1サイト2万ファイル・1ファイル25MBまで）、独自ドメインも無料で付けられます。
    
    
      
      
    1. Cloudflare に無料登録して、ダッシュボードの「Workers & Pages」から Pages の新しいプロジェクトを作り、「アセットをアップロード（直接アップロード）」を選びます。
      2. 
      
    2. プロジェクトの名前を決めます。これが 名前.pages.dev というアドレスになります。
      3. 
      
    3. 「公開用」フォルダ（または「…_公開用.zip」）をドラッグします。ドラッグで入れられるのは1,000ファイルまでです（zip でも同じです）。写真が多くて超えるときは、下の Netlify Drop を試してください。
      4. 
      
    4. 「デプロイ」を押すと、数十秒で公開されます。
      5. 
    
    
    
    1,000ファイルを超えるとき：Netlify Drop
    
    
      
      
    1. app.netlify.com/drop を開き、「公開用」フォルダをドラッグします。写真が多いと、入れ終わるまで数分かかります。
      2. 
      
    2. ログインせずに入れると、合言葉つきで1時間だけ見られる「仮公開」になり、そのままだと消えます。
      3. 
      
    3. 画面の「Claim this site」から無料アカウントを作ってサイトを引き取ると、正式に公開されます。
      4. 
    
    
    
    公式の案内では、全体で50MB未満が最適で、1ファイルが10MBを超えると止まることがあります（Netlify Drop の説明）。こちらでは1,801ファイル・540MBを入れて、約4分で全部のファイルが表示されることを確かめました（2026年11月）。無料枠は月300クレジットで、転送量1GBごとに20クレジット使います。使い切ると翌月までサイトが止まります。
    

    
    独自ドメイン（自分のアドレス）を付け替える
    
    
      
      
    1. Cloudflare Pages ならプロジェクトの「カスタムドメイン」、Netlify なら「Domain management」で、自分のドメイン（例 www.example.com）を追加します。
      2. 
      
    2. 画面に「この値を DNS に設定してください」と出ます。www.example.com のように前に www などが付くアドレスなら、CNAME という種類で、行き先が 名前.pages.dev の設定を1つ足すだけです。example.com のように前に何も付かないアドレスを Cloudflare Pages で使うときは、ドメインの管理（ネームサーバー）を Cloudflare に移す必要があります（画面の案内に沿って進めます）。
      3. 
      
    3. ドメインを買った会社（お名前.com、ムームードメインなど）の DNS 設定を開き、いまの Ameba Ownd 向けの設定を、その値に書き換えます。
      4. 
      
    4. 反映には数分〜数時間かかります。https://自分のドメイン/posts/記事の番号 が開ければ完了です。
      5. 
    
    
    
    付け替えると、そのアドレスでは Ameba Ownd のサイトは表示されなくなります。写真の保存と新しいサイトの確認を先に済ませてください。○○.amebaownd.com などの Ameba Ownd のアドレスは引き継げないので、下の「訪問者へのお知らせ」で新しいアドレスを知らせます。
    

    
    「訪問者へのお知らせ」の文を作る
    
    
    Ameba Ownd の管理画面では、訪問者に200文字までのお知らせ（ポップアップやバナー）と、リンクのボタンを出せます。ボタンの文は「移設後のサイトはこちら」を選ぶと分かりやすいです。

    よくある質問
    
    
    本当にお金はかかりませんか
    
    
    この道具は無料です。Cloudflare Pages・Netlify の無料の範囲で公開できます。独自ドメインの料金（毎年の更新料）は、これまでどおりドメインの会社に払います。
    
    
    写真は何枚まで保存できますか
    
    
    「フォルダに直接保存」なら、パソコンの空き容量の範囲で何枚でも保存できます。1枚10MB前後の写真もあるので、写真1,000枚なら数GBの空きを用意してください。
    
    
    WordPress に移りたいのですが
    
    
    WordPress.com なら zip を解凍せずにそのまま、WordPress.org（自分のサーバー）なら zip を解凍して「-01.xml」から順に1つずつ取り込みます（公式の手順）。写真は取り込みのときに Ameba Ownd から読み込まれるため、終了日までに取り込みを済ませる必要があります。念のため、ここで写真を保存しておくと安心です。
    
    
    書き出しファイルの形が違っていたら
    
    
    公式の手順（2026年11月18日）では、書き出しは WordPress の標準の形（WXR）の XML で、件数が多いと「-01.xml」「-02.xml」…に分かれます。この道具はその形を読み、項目が欠けていても読めるように作っています。ただ、本物の書き出しファイルではまだ確かめられていません。読めなかったときは、出てきたメッセージと、読み込んだあとに出る「形式の診断」（ファイルの形だけで、中身は入りません）を添えて @ViewsEngineer に知らせていただけると直します（ファイルそのものは送らないでください）。

    終了日を過ぎると、写真は取り出せません。必要な人に届くよう、共有してください。
