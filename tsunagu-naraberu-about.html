About — ツナラベ！

4つつなげる盤と、
3つ並べる盤が、戦う。

ツナラベ！は、ブラウザで遊べる対戦パズルです。 上から落ちてくる2個1組を積んで同じ色を4つつなげるつなぐ派（ぷよぷよ風）と、 下からせり上がる盤でパネルを入れ替えて3つ並べるならべる派（パネルでポン風）が、ルールのちがう盤のまま直接戦います。 無料で、登録もインストールもいりません。CPU 戦は PC とスマホで、ふたり対戦は1台の PC で遊べます。

01 — Whatどんなゲームか

ふつうの対戦パズルは、両方の人が同じルールの盤で戦います。ツナラベ！では、落ち物の盤と入れ替えパズルの盤が向かい合います。 どちらの派も、消すと共通の「ダメージ値」が出ます。ダメージは相手の盤の流儀に変換されて降るので、つなぐ派にはおじゃまのつぶ、ならべる派には横長のおじゃまブロックが落ちます。 先に盤が積み上がった方の負けです。

つなぐ派（ぷよぷよ風）

上から落ちてくる2個1組を積み、同じ色を4つつなげて消します。消えたあとに落ちたつぶがまたそろうと連鎖になり、大きな連鎖ほど相手に多くのおじゃまを送れます。 おじゃまのつぶは、隣で消すと消えます。

ならべる派（パネルでポン風）

下からせり上がる盤で、横2マスのカーソルでパネルを入れ替え、縦か横に3つ以上並べて消します。同時に4つ以上消すと同時消し、落ちたパネルがそろうと連鎖になります。 消えたあと上のパネルは少しのあいだ浮くので、その下にパネルを差し込んで連鎖をつなぐ「アクティブ連鎖」もできます。 盤が天井に届いても3秒の猶予があり、同時消しや連鎖でせり上がりを止める「停止時間」がもらえます。おじゃまブロックは、隣で消すと下の1行がパネルに戻ります。

02 — How to fight相殺と、攻撃の強さ

  1. 予告が出る — 盤の上に並ぶ灰色の玉・四角が、もうすぐ降ってくるおじゃまの予告です（右の数字が量）。
  2. 3秒は降らない — 数字の横のゲージが満ちるまでの3秒は降りません。
  3. 打ち返して相殺 — その間に消して攻撃すると、攻撃はまず自分の予告にぶつかって打ち消します（光が予告に当たって砕けます）。余った分だけが相手に飛びます。
  4. 赤くなったら降る — ゲージが赤くなると、つなぐ派は次に組を置いたとき、ならべる派は消している最中でなければ降ります。

開始60秒は攻撃が弱めで、90秒を過ぎると15秒ごとに攻撃が強くなります。長引くほど、一度の連鎖で決着がつきやすくなります。

03 — Modesモードと CPU の強さ

  • CPU と対戦 — 5段階の強さの CPU と戦います。PC とスマホで遊べます。
  • ふたりで対戦 — 1台の PC で、ふたりで。腕に差があるときは、攻撃力を1段ごとに20%ずつ上げ下げするハンデをつけられます。
  • れんしゅう — 相手なしで自分の盤だけを触れます。おじゃまを降らせる練習もできます。
  • あそびかた — 操作しながら覚えるチュートリアル（約1分）。つなぐ派は5課題、ならべる派は6課題です。
  • 戦績 — 勝率・最大連鎖・最大攻撃が残ります。

CPU の5段階

かんたんはじめての人に。ゆっくり考える CPU
やさしいルールに慣れてきたら
ふつう連鎖が組めるようになったら
つよい上級者向け。連鎖でしっかり攻めてくる
おに腕に自信のある人に

どちらを選んでも、同じくらい勝てる

変換の比率や CPU の強さは勘で決めていません。人の腕前を「初心者・ふつうの人・上手な人」の3段階に模したプレイヤー（手の速さ・反応の遅れ・読みの深さを人並みに合わせたもの）を作り、 各段の CPU と両方の派で数百試合ずつ自動で対戦させて調整しました。目安は、かんたんは初心者が6割ほど勝てる、やさしいはふつうの人が6割、ふつうは4〜5割、つよいは上手な人が4割、おには2割です。 そのため CPU の速さや攻撃の強さは、段と派によって少しずつ変えています（人が操作する側には補正はかかりません）。

04 — Controls操作

PC（キーボード）

つなぐ派：AD（←→）移動・S 速く落とす・W すぐ落とす・F/G（Z/X）回転
ならべる派：WASD（矢印）カーソル・F（Z）入れ替え・G（X）押している間せり上げ
ふたりで対戦：左は WASD＋FG、右は矢印＋;'

キーの割り当て・連続移動の速さは「操作の設定」で変えられます。ゲームパッドも使えます。

スマホ（タッチ）

つなぐ派：盤の上で指を横にすべらせて移動、タップで回転（左半分は左回転）、下へはじいてすぐ落とす（画面下のボタンも使えます）。
ならべる派：パネルを左右になぞって入れ替え、下のボタンを押している間せり上げ。

06 — FAQよくある質問

ツナラベ！は無料ですか。登録は必要ですか。
無料です。会員登録もアプリのインストールもいりません。ブラウザでページを開けば、そのまま遊べます。
スマホでも遊べますか。
スマホではタッチ操作で CPU と対戦できます。ふたり対戦は1台の PC のキーボードで遊びます。
ふたりで対戦できますか。
1台の PC で、ふたりで対戦できます。左の人は WASD と F・G、右の人は矢印キーと ; と ' を使います（操作の設定で変えられます）。ゲームパッドも使えます。
どちらの派を選ぶと有利ですか。
同じ腕前なら同じくらい勝てるように調整しています。調整のしかたは「モードと CPU の強さ」に書いています。
ぷよぷよやパネルでポンの公式ゲームですか。
ちがいます。「ぷよぷよ」は株式会社セガの、「パネルでポン」は任天堂株式会社の商標で、本作は各社とは関係のない非公式の作品です。遊びの感触を伝えるために「〜風」と書いています。
AI で作ったのですか。
AI を使って作りました。音楽と効果音は Suno、キャラクターの声は ElevenLabs、キャラクターの絵は Stable Diffusion（WAI-Illustrious）で作り、ゲームの中のヘルプにも書いています。登場するのは、つなぐ派のひなた・もも（相棒ぷにまる）と、ならべる派のりん・すず（相棒カクたん）です。
