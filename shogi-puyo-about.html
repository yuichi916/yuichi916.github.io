About — Shogi Puyo

将棋の駒で、
連鎖を組む。

将棋ぷよ「成」は、将棋の駒を使った落ちものパズルです。 上から2つ1組で落ちてくる駒を、同じ種類どうし4つつなげて消します。強い駒を消すほど、連鎖を重ねるほど、多くのお邪魔駒を相手の盤に送れます。 相手は CPU で、先に相手の盤を埋めて「詰ませた」方の勝ちです。 ブラウザで無料、登録もいりません。PC でもスマホでも遊べます。

01 — Rule基本のルール

盤は横6列・縦12段です。駒は歩・銀・金・角・飛の5種類で、将棋のように動かすことはなく、色の代わりに使います。 同じ駒がたて・よこに4つ以上つながると消え、上の駒が落ちて次の組がそろうと連鎖になります。

消した駒が強いほど、相手に送るお邪魔駒が増えます。送る量は、消した駒の強さの合計（成った駒は2倍）をもとに、 連鎖が1段ふえるごとに 1.6 倍ずつ大きくなります。連鎖を重ねるほど、送る量は大きくふくらみます。

歩銀金角飛
強さ 1強さ 2強さ 3強さ 4強さ 5
成ると「と」成ると「全」成らない成ると「馬」成ると「龍」

届いたお邪魔駒は、すぐには降りません。盤の上に2手ぶんためられ、予告が「安全 → 警戒 → 危険」と近づき、危険になると次の駒で落ちてきます。 そのあいだに自分で連鎖を組めば、届いたお邪魔駒を打ち消す（相殺する）ことができます。 盤に落ちてきたお邪魔駒は、となりの駒の群れが消えるときにいっしょに消えます。

02 — Gimmicks将棋らしい仕掛け

成り

駒が消えたとき、そのすぐそばで生き残った駒が「成り」ます。成っても駒の種類は変わらないので、消し方（同じ駒を4つ）はそのままです。成った駒は金色の縁と成り字で示され、次に消したときに送るお邪魔駒が2倍になります。 金は将棋と同じく成りません。

王（玉将）

6手目以降、ときどき組の片方が玉将になって降ってきます。16手のあいだ出なければ、必ず出てきます。 王のとなりの駒の群れを消すと「討ち取り」になり、強力なお邪魔駒を送れます。

将棋魂と王手

消した駒の価値で「将棋魂」がたまります。72 たまると「王手」になり、次に相手へ送るお邪魔駒が 4 つ増えます。

連携と同時攻め

  • 三駒連携 — 一つの連鎖で3種類の駒を消すと、お邪魔駒 +2・将棋魂 +12。
  • 同時攻め — 同時に2組を消すと、お邪魔駒 +1・将棋魂 +6。

奥義・金剛詰め

駒を消すと奥義のゲージがたまります。満タンのときに使うと、届いているお邪魔駒を最大 8 個打ち消し、4 個を送り返します。 奥義を使わずに遊びたいときは、右上の「奥」のボタンで切れます。

CPU と、6人のキャラクター

CPU の強さは「やさしい・ふつう・つよい」の3段階です。CPU は盤を写しとって置き場所を試しながら手を選び、「つよい」は次に来る駒まで読みます。強くなるほど駒の落ちる速さと CPU の手の速さが上がり、「やさしい」の CPU はときどき手を誤りますが、「つよい」の CPU は誤りません。 対局中は、駒にちなんだ名前の6人（歩乃・銀花・金士郎・角夜・飛蓮・王華）が、連鎖や相殺、王手の場面で声つきのひとことを話します。

03 — Controls操作

PC（キーボード）

←→ 移動、↓ 落下、Z・X・↑ 回転、A 180°回転、 Space 一気に落とす、C 奥義、P・Esc 一時停止。

スマホ（タッチ）

盤の左右をタップすると回転、上にフリックすると左回転、横にスワイプすると移動、下にフリックすると一気に落とします。 画面の下にも、左右の回転・移動・落下・一気・奥義のボタンがあります。

画面の見方

左があなたの盤、右が CPU の盤です。中央の NEXT と NEXT 2 に、次とその次に落ちてくる組が出ます。 盤のそばには点数と連鎖数、将棋魂と奥義のたまり具合、次に送る予定のお邪魔駒の数（攻め予定）が表示されます。

右上のボタンで、効果音・BGM・キャラクターボイスをそれぞれ切り替えられます。「？」から遊び方をいつでも見られます。

05 — How it's madeどうやって作ったか

ゲームは1枚の HTML ファイルで、盤と駒は canvas に描いています。外部のゲームエンジンは使っていません。コードは Claude Code で書きました。

作るときは、駒が消える判定や連鎖の計算、お邪魔駒の落とし方といった中心の部分を画面から切り離して単体で試し、 CPU どうしを最後まで対局させて止まらないことを確かめてから、実際の画面で描画を確かめました。
