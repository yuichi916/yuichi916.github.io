# AIエージェント能力アトラス — 調査ブリーフ（2026-09-06 時点）

## 目的
「2026年9月時点でAIエージェントに何ができて、何ができず、いつできるようになりそうか」を、
専門家との比較で、根拠つきで、MECEな階層データとして作る。ベンチマークスコアではなく
**具体的なタスク単位**で判定する。

## 出力形式（厳守）: JSON 1ファイル
```json
{
  "domain": "<L1 id>",
  "areas": [
    {
      "id": "content.novel",            // L2 id: "<domain>.<slug>"
      "name": "小説・物語",
      "name_en": "Fiction",
      "tasks": [
        {
          "id": "content.novel.short_story",   // L3 id
          "name": "短編小説を書く（〜1万字）",
          "name_en": "Write a short story",
          "levels": {"2022":1,"2023":2,"2024":3,"2025":3,"2026":4,"2027e":4,"2028e":5,"2030e":5},
          "vs_expert": "上位20%のプロには届かないが、商業誌の平均的な短編とは見分けがつかないレベル（審査実験の引用）",
          "can": "プロット指定→一発で構造の通った短編。文体模倣。複数案の並列生成",
          "cannot": "10万字級で伏線を破綻なく回収する／読者の記憶に残る独自の声／推敲での自己評価が甘い",
          "why": "長距離一貫性とテイスト判定の弱さ。自己評価が甘いのは訓練上の理由",
          "autonomy": "copilot|agent|autonomous",   // 2026-09時点で現実的な運用形態
          "tools": ["Claude Fable 5.1", "GPT-5.x", "Sudowrite"],
          "evidence": [
            {"title": "…", "url": "https://…", "date": "2026-08", "note": "何が示されたか1行"}
          ],
          "forecast_basis": "2028年に5にした根拠（傾向・発表・ロードマップ）1〜2行"
        }
      ]
    }
  ]
}
```

## レベル定義（0〜5、必ずこの意味で）
| lv | 名前 | 意味 |
|---|---|---|
| 0 | できない | 試みても使い物にならない／そもそも入出力が定義できない |
| 1 | デモ止まり | 選り抜き例なら見せられるが実務では使わない |
| 2 | 補助 | 人が主・AIが下書き/候補出し。人の作業量を2〜5割減らす |
| 3 | 実務品質(要確認) | ジュニア専門職の成果物相当。人が確認すればそのまま出せる。自律で数十分〜数時間のタスク |
| 4 | 専門家並み | 自律で多くの専門家に匹敵。まれに確認。数時間〜数日のタスクを完走 |
| 5 | 専門家超え | 専門家の9割より上、または人には物理的に不可能な規模・速度 |

## 時点
"2022"(ChatGPT公開前後), "2023"(GPT-4), "2024", "2025", "2026"(=2026年9月の現在), "2027e", "2028e", "2030e"。
予測(e)は根拠を forecast_basis に必ず書く。当てずっぽうの楽観は禁止。停滞するものは停滞と書く。

## 調査の質
- WebSearch/WebFetch で **2026年の一次情報**（公式発表、論文、ベンチマーク、実務レポート、ユーザー報告）を優先。2025年以前の情報だけでレベル判定しない。
- 「できない」は特に重要。失敗事例・限界の報告を積極的に集める（成功談だけの偏りを避ける）。
- 各 task に evidence を最低1件、可能なら2〜3件。URLは実在するものだけ。
- MECE: 同じ領域内でタスクが重複しないよう、L2を先に固めてからL3を埋める。
- 深さ: L2 は 5〜9 個、L3 は各 4〜8 個（領域全体で 25〜50 タスク）。
- 主要モデル名（2026-09時点）: Claude Fable 5.1 / Opus 5 / Sonnet 5、GPT-5系、Gemini 3系、Grok、DeepSeek、Qwen等。検索で最新名を確認して使う。

## 書き出し先
指定されたパスに UTF-8 の JSON として保存。JSONとして valid か python -c "import json;json.load(open(p,encoding='utf-8'))" で確認してから終了。
最後に、収集した中で「意外だった事実」「見出しになる事実」を5つ、チャット返答に箇条書きで返す。
